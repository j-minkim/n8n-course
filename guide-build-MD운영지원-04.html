04. ✍️ 방송 자막·상세 카피 생성기

상품 정보를 넣으면 Claude가 방송 자막 3안 + 상세페이지 문구 + 채팅 응대 멘트를 만들어 날짜별 CSV로 저장합니다.

받는 사람: 본인(수동 실행) · 분류: MD·운영 지원 · 데이터 파일: 카피요청.csv 헤더: 상품명 · 핵심특징 · 가격 → 결과는 카피결과_날짜시각.csv로 자동 저장 — ~/.n8n-files에 넣기

처음 만드는 필드 종류(노드 추가·연결·표현식 토글·크리덴셜)는 공통 조작법을 먼저 보세요.

🤖 경로 A — Claude Code에게 시키기 (메타프롬프트)

이 강의의 방식대로, 아래 프롬프트를 Claude Code에 그대로 붙여넣으면 이 워크플로 JSON을 만들어줍니다(n8n-MCP 연결 시 더 정확). 받은 JSON을 ⋮ → Import from File로 불러온 뒤 노드별 Test step으로 검증하세요 — AI 초안은 가설, 진실은 에디터 실행 결과입니다.

n8n 워크플로 JSON을 만들어줘: "방송 자막·상세 카피 생성기" 자동화야. (데이터는 CSV 파일 기준)

[목표] CSV의 상품 정보로 Claude가 방송 자막 3안 + 상세페이지 문구 + 채팅 응대 멘트를 만들어 날짜별 결과 CSV로 저장. (수동 실행형)

[노드 체인 — 7개]
1. Manual Trigger — ▶ 수동 실행
2. Read/Write Files from Disk — 읽기: YOUR_DATA_DIR/카피요청.csv (헤더: 상품명·핵심특징·가격)
3. Extract from File — CSV 파싱. ★노드 이름 '카피 요청 읽기'(뒤 Code가 $()로 참조)
4. HTTP Request(POST) — Claude에게 "(1) 방송 자막 문구 3안(각 20자 내외, 자극적이지 않게)
   (2) 상세페이지 소개 문구 3문장 (3) 실시간 채팅 응대 멘트 2개.
   ★과장·허위·의료효능 표현 금지"를 요청. 상품명·핵심특징·가격 포함. (max_tokens 900)
5. Code — $('카피 요청 읽기')의 상품명 + Claude 응답(content[0].text)을 {상품명, 생성카피}로 정리.
6. Convert to File — CSV 변환 (노드 이름 '카피결과 CSV 변환')
7. Read/Write Files from Disk — 쓰기: YOUR_DATA_DIR/카피결과_{{ $now.format('yyyy-LL-dd_HHmm') }}.csv (노드 이름 '카피 결과 저장')

★주의: 생성된 카피는 송출 전 반드시 사람이 최종 검수(방송 심의).

[공통 규칙 — 그대로 지켜줘]
- n8n-MCP가 연결돼 있으면 각 노드의 정확한 파라미터를 조회해서 만들고, 없으면 표준 노드 구조로.
- 데이터는 CSV 파일 기준: 경로는 YOUR_DATA_DIR/… 플레이스홀더로.
  (self-host n8n은 ~/.n8n-files 안의 파일만 접근 가능 — 사용자가 절대경로로 교체할 것)
- Claude 호출은 HTTP Request 노드로: POST https://api.anthropic.com/v1/messages,
  인증은 Header Auth 크리덴셜(이름 x-api-key), 추가 헤더 anthropic-version: 2023-06-01,
  모델 claude-sonnet-5, 응답 본문은 content[0].text 로 파싱.
- 수신자 이메일은 YOUR_...@example.com 플레이스홀더로.
- connections의 타입은 전부 "main". IF 노드는 true 출력만 다음 노드로.
- 완성되면 워크플로 JSON을 파일로 저장해줘 — 내가 n8n에서 ⋮ → Import from File 로 불러올게.
- import 후엔 노드별 Test step으로 하나씩 검증할 거야(통째로 맞다고 가정하지 말 것).

🗂 이 프롬프트는 기본(파일 버전) 기준입니다. 팀 공유용 구글시트 버전(보조)이 필요하면 파일 버전 가이드 §4의 시트 변환 단락을 덧붙이세요.

🔧 경로 B — 손으로 직접 만들기 (스텝바이스텝)

노드가 왜 이 순서로 놓이는지 이해하려면 이 경로로. 아래 Step은 기본(파일 버전) 기준입니다 — 구글시트 버전(보조)은 파일 노드 2단 자리에 Google Sheets 노드 1개가 들어갑니다: 차이 보기

노드 순서 (총 7개): ▶ 실행 (수동) → 카피요청 파일 읽기 → 카피 요청 읽기 → Claude 카피 생성 → 결과 정리 → 카피결과 CSV 변환 → 카피 결과 저장

Step 1 — ▶ 실행 (수동) 추가

  • 검색어: 없음 — 빈 캔버스를 열면 기본 제공되는 "Trigger manually" 노드를 그대로 사용(또는 노드 패널에서 Manual Trigger 검색)
  • 속성 설정: 없음(설정할 필드 없음)
  • 연결: 이 노드가 시작점입니다.

Step 2 — 카피요청 파일 읽기 추가

  • 검색어: Read/Write Files from Disk
  • 속성 설정:
    • Operation = Read File(s) From Disk (기본값)
    • File(s) Selector = YOUR_DATA_DIR/카피요청.csv → YOUR_DATA_DIR를 본인 ~/.n8n-files 절대경로로 교체
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 출력에 파일이 바이너리(data)로 잡히는지 확인. 파일이 없거나 허용 폴더 밖이면 여기서 에러.

Step 3 — 카피 요청 읽기 추가

  • 검색어: Extract from File
  • 속성 설정: Operation = Extract From CSV (기본 필드 그대로 · 엑셀 파일이면 Extract From XLSX)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 CSV 각 행이 JSON 아이템으로 나오는지(헤더 = 필드명) 확인 — 여기서부터는 시트 버전과 데이터 모양이 완전히 같습니다.

Step 4 — Claude 카피 생성 추가

  • 검색어: HTTP Request
  • 속성 설정:
    • Method = POST
    • URL = https://api.anthropic.com/v1/messages
    • Authentication = Generic Credential Type → Generic Auth Type = Header Auth → Credential = 공통 조작법에서 만든 x-api-key 크리덴셜 선택
    • Send Headers = On → Add Header 2번:
      • anthropic-version = 2023-06-01
      • content-type = application/json
    • Send Body = On → Body Content Type = JSON → Specify Body = Using JSON → 필드의 표현식 토글(=) 켜고 아래를 그대로 붙여넣기:
{{ JSON.stringify({ model: 'claude-sonnet-5', max_tokens: 900, messages: [{ role: 'user', content: '홈쇼핑 방송/상세페이지 카피라이터다. 아래 상품 정보로 (1) 방송 자막 문구 3안(각 20자 내외, 자극적이지 않게) (2) 상세페이지 소개 문구 3문장 (3) 실시간 채팅 응대 멘트 2개 를 한국어로 만들어줘. 과장·허위·의료효능 표현 금지.\n상품: ' + $json['상품명'] + ' / 핵심특징: ' + ($json['핵심특징']||'') + ' / 가격: ' + ($json['가격']||'') }] }) }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 content[0].text에 Claude의 응답 문장이 들어있는지 확인. invalid x-api-key 에러면 크리덴셜 값을 다시 확인하세요.

Step 5 — 결과 정리 추가

  • 검색어: Code
  • 속성 설정: Mode = Run Once for All Items (기본값, 바꾸지 않음) → JavaScript 편집창에 아래 코드를 그대로 붙여넣기:
return [{json:{상품명:$('카피 요청 읽기').item.json['상품명'], 생성카피:$json.content[0].text}}];
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 눌러서 출력 JSON에 기대한 필드(위 코드의 return에 있는 키들)가 정확히 나오는지 확인하세요. 여기서 필드명 오타가 나면 다음 노드부터 전부 빈 값이 됩니다.

Step 6 — 카피결과 CSV 변환 추가

  • 검색어: Convert to File
  • 속성 설정: Operation = Convert to CSV (엑셀로 저장하려면 Convert to XLSX)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 7 — 카피 결과 저장 추가

  • 검색어: Read/Write Files from Disk
  • 속성 설정:
    • Operation = Write File to Disk
    • File Path and Name: 표현식 토글(=) 켜고 → YOUR_DATA_DIR/카피결과_{{ $now.format('yyyy-LL-dd_HHmm') }}.csv
    • Input Binary Field = data (기본값)
    • YOUR_DATA_DIR는 본인 ~/.n8n-files 절대경로로 교체 (macOS /Users/계정/.n8n-files · 윈도우 C:\Users\계정\.n8n-files)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: 실행 후 폴더에 날짜가 붙은 파일이 생겼는지 확인. Access to the file is not allowed 에러면 경로가 ~/.n8n-files 밖입니다(에러 전문을 Claude Code에 붙여넣으면 해결).

✅ 완성 후 테스트: 트리거 노드에서 Test step(또는 Execute Workflow) → 마지막 노드까지 전부 초록불이 뜨는지 확인. 안 뜨면 그 노드를 더블클릭해 에러 메시지를 읽고, 표현식 토글(=)이 켜져 있는지부터 확인하세요.
