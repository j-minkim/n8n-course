# n8n 실습 키트 assets 안내

이 폴더는 n8n 자동화 강의 실습용 데모 데이터, 프롬프트, import용 워크플로 JSON을 담아요. 실습 환경은 **각자 노트북에 `npx n8n`으로 띄운 로컬 self-host** 기준이에요. (Claude Code가 설치를 주도하고, 데이터는 `~/.n8n`에 저장돼요.)

## 1. 데모 데이터 (`data/*.csv` → 구글시트로 import)

CSV 4종을 구글시트 **탭(시트)**으로 업로드해서 써요. 매출 값은 콤마 없는 정수라서 숫자 비교가 바로 돼요.

| 파일 | 구글시트 탭 이름 | 사용 랩 | 용도 |
|---|---|---|---|
| `data/편성표.csv` | `편성표` | Lab1 | 방송 편성표(시간·방송명·담당자·메일·상품군) → 담당자 메일 발송 |
| `data/일일매출.csv` | `일일매출` | Lab2, Lab3 | 하루치 방송 매출/목표매출 8행 → 조건분기·집계 |
| `data/주간매출.csv` | `주간매출` | Lab4 | 한 주치(06-02~06-08) 매출 15행, 상품군 반복 → 주간 집계 |
| `data/CS문의.csv` | `CS문의` | Lab4-AI | 고객 문의 6건 → AI 분류·요약 |
| `data/일일매출_콤마.csv` | (선택) `일일매출_콤마` | Lab2 흔한실수 시연 | 매출/목표매출이 `"12,000,000"` 콤마 문자열 → **숫자비교 실패 → 콤마제거/Number 변환** 시연용 |

### 추가로 만들어 둘 빈 탭 (결과 기록용)

워크플로가 결과를 append 하는 빈 탭 2개를 미리 만들어 두세요.

- `요약시트` — Lab2(미달 기록), Lab3·Lab4(상품군별 집계 결과)가 append 돼요.
- `분류결과` — Lab4-AI의 CS 분류·요약 JSON 결과가 append 돼요.

> 강의 전 본인 로컬 `npx n8n`에서 dry-run 1회 확인: CSV 업로드 후 각 탭의 열 이름이 위 헤더와 정확히 일치하는지, 구글시트 노드 read가 녹색으로 통과하는지 확인하세요. (UI 클릭 경로/노드 파라미터는 n8n 버전마다 다를 수 있어요.)

## 2. import용 워크플로 JSON (`import/*.json` — "Import from File")

JSON 6종을 n8n에서 **Import from File**로 불러온 뒤, 자격증명(구글/Gmail/Anthropic)과 시트ID를 본인 것으로 교체하고 각 1회 실행하세요.

| 파일 | 용도 |
|---|---|
| `import/lab1-편성표메일.json` | Lab1 완성본 — 스케줄(매일 09:00) → 편성표 읽기 → 담당자 메일 (강사 시연/참고) |
| `import/lab2-조건분기.json` | Lab2 — 일일매출 읽기 → 목표미달 IF(매출 < 목표) → 미달 기록 append |
| `import/lab3-다중출력.json` | Lab3 — 일일매출 읽기 → 상품군 집계(Summarize) → 요약시트 기록 + 요약 메일(분기) |
| `import/lab4-checkpoint1-집계까지.json` | Lab4 체크포인트① — 주간 스케줄(월 08:00) → 주간매출 읽기 → 집계 → 요약시트 기록. **게이트① 미통과자가 불러와 합류** |
| `import/lab4-checkpoint2-발송까지.json` | Lab4 체크포인트② — ① + 포맷팅·다중발송·에러핸들링. **AI 노드 직전 상태**(게이트② 합류용) |
| `import/lab4-complete-AI포함.json` | Lab4 완성본 — ② + AI 분류/요약 브랜치(CS문의 읽기 → 분류요약 체인 → 분류결과 기록). 핸즈온 최종 참고본 |

> 체크포인트①②는 낙오자가 후반부터 합류하기 위한 중간 저장본이에요. dry-run 때 ① → ②로 이어지는지(요약시트 집계값이 다음 단계 입력으로 들어가는지) 꼭 확인하세요.

## 4. 비용·한도 안내 (사실 고정값 — 멘트 준비용)

- **Claude Pro = 월 $20 (USD)**: claude.ai 챗 + 설계·디버깅 보조 **전용**. n8n 워크플로 AI 노드 구동에는 못 써요.
- **n8n 워크플로 AI 노드**: 별도 **Anthropic API 키**(console.anthropic.com · 종량과금) 필수. (회사가 키 제공 → 수강생 직접 핸즈온)
- **`npx n8n` self-host는 무료** (Cloud 구독료 비교 불필요). 단 워크플로 안 Anthropic 노드는 별도 API 키(종량과금)예요.
- **스케줄 타임존 = Asia/Seoul (UTC+9)**: `GENERIC_TIMEZONE=Asia/Seoul npx n8n`으로 설정(미설정 시 America/New_York).
- **Gmail 발송 한도**: 무료 계정 500/일, Workspace 2,000/일.
- **로컬 self-host(`npx n8n`) Webhook**: n8n Cloud(Cloudflare)의 100초/524 제한은 직접 받지 않아요. 단 브라우저·프록시·터널·동기 Webhook 응답 timeout은 별도 변수예요. 페이로드 기본 16MiB(`N8N_PAYLOAD_SIZE_MAX`로 조정 · 공식 문서 기준).
