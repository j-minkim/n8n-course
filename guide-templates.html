파일명 앞 **L1~`L5`**가 난이도예요. 번호가 낮을수록 노드가 적고 단순합니다. 강의에서 쓰는 순서와 같아요.

레벨 무엇이 새로운가 대표 템플릿 강의 연결
L1 단일 선형 트리거→읽기→내보내기 (분기·외부·AI 없음) 편성표 아침알림·신규주문·방송실적 리포트 1주차 복습
L2 분기·다중출력 IF로 나누기 / 여러 곳 동시 발송 재고부족 알림·일일매출 다중발송 1주차 복습
L3 외부 API HTTP로 외부 데이터 가져오기(비AI) 경쟁사 가격 모니터링 응용
L4 AI 워크플로 Claude 노드로 분류·요약·생성 CS문의 분류·VOC 분류·뉴스 브리핑 B3~B4 AI 실전
L5 실무 복합 AI+분기+외부+다중 결합 실무 10종(가격경쟁력 진단이 최상) B5~B7 나만의 자동화

💡 처음이면 L1부터 · AI가 처음이면 L4 「CS 문의 분류」 · 도전은 L5 「가격경쟁력 진단」.

홈앤쇼핑 n8n + Claude 템플릿 카탈로그

"처음부터 만들지 말고, 내 업무에 가까운 걸 골라 시작하세요"

각 템플릿은 실제 n8n에서 import·구조 검증됐어요(실행은 자격증명 연결 후 재검증). 본인 업무에 가까운 것을 import → 시트·수신자·자격증명만 맞추면 절반은 완성, 거기서 본인 것으로 확장하면 됩니다.

💡 다건 행 처리 팁: 시트에 여러 행을 매번 처리하려면 해당 Code 노드 설정을 Run Once for Each Item으로 바꾸고 return을 단일 객체(return {json:{...}})로 수정하세요(기본값은 첫 행만 처리).

📥 바로 다운로드 (n8n ⋮ → Import from File로 불러오기): 전체 20종 zip · 기본 10종만 · 실무 10종은 경쟁사조사 · 방송운영 · MD운영지원 · ★구글 크리덴셜 없이 쓰려면 파일(CSV) 버전 — 그 외 파일은 실습 파일 전체 목록 🧱 직접 만들어보기: import 대신 노드 하나씩 손으로 쌓아보려면 → 실무 10종 스텝바이스텝 빌드 가이드 (템플릿별 개별 페이지, 노드 검색어·속성값·연결법까지 상세) ⚙️ 공통 준비: Google 크리덴셜(연결됨) · AI(★) 템플릿은 회사 Anthropic 키(Header Auth 이름 x-api-key) · YOUR_... 자리(시트 ID·수신자) 교체 🤖 AI 모델: 템플릿은 claude-sonnet-5(현행)로 설정 — 필요 시 최신 모델로 교체. ✅ 검증 수준: 전 템플릿 n8n import·구조 검증 완료. 실제 실행은 자격증명 연결 후 재검증하세요.

⚠️ 네이버 검색 API 종료 예정(2026-07-31): 「가격경쟁력 진단」이 쓰는 네이버 검색 API가 종료 예정입니다 → 그때까지는 동작하나, 이후엔 NAVER API HUB로 이전 필요.

🧑‍💼 MD · 상품기획이라면

L5 ⭐ 방송상품 가격경쟁력 진단 (★AI)

  • 뭘 하나: 방송 예정 상품이 인터넷 최저가보다 비싼지 매일 아침 자동 점검. 네이버쇼핑에서 상품 최저가를 찾아 우리 방송가와 비교하고, 비싸면 Claude가 방송에서 쓸 대응 멘트(방송 한정가·추가 사은품·차별화 포인트)를 뽑아 MD에게 메일.
  • 왜 좋은가: 홈쇼핑 MD의 핵심 고민 — "내 방송가가 인터넷보다 비싸면 안 팔린다"를 그대로 자동화.
  • 필요한 것: 네이버쇼핑 API 키(무료)·회사 Anthropic 키·방송예정상품 시트(상품명·우리방송가)
  • 확장: 알림을 슬랙으로 / 경쟁 홈쇼핑 특정 몰만 비교 / 가격 추세 아카이브

L5 방송 결과 리포트 자동 초안 (★AI)

  • 뭘 하나: 방송 종료 후 매출·주문·콜·반품 지표를 모아 Claude가 "잘된 점 / 아쉬운 점 / 다음 개선안" 리포트 초안을 써서 MD에게. 매 방송 리포트 수작업을 없앰.
  • 필요한 것: Anthropic 키·방송결과 시트(방송명·목표매출·매출·주문·콜·반품)

L5 협력사 발주 개인화 메일 (★AI)

  • 뭘 하나: 재고 부족한 협력사마다 Claude가 벤더별 맞춤 발주확인 메일을 써서 담당자에게 개별 발송. 수십 벤더에 비슷한 메일 반복을 없앰.
  • 필요한 것: Anthropic 키·발주현황 시트(협력사·담당자메일·상품·발주필요수량)

L5 방송 자막·상세 카피 생성기 (★AI)

  • 뭘 하나: 상품 정보를 넣으면 Claude가 방송 자막 3안 + 상세페이지 문구 + 채팅 응대 멘트를 만들어 시트에 저장. (과장·의료효능 표현 금지 프롬프트 내장 — 송출 전 사람 검수)
  • 필요한 것: Anthropic 키·카피요청 시트(상품명·핵심특징·가격)

L4 주간 리포트 + AI 코멘트 (★AI)

  • 뭘 하나: 주간 상품군별 매출을 집계하고 Claude가 MD용 인사이트 코멘트를 붙여 팀에 발송.

📺 편성 · 생방송 운영이라면

L5 ⏱ 생방송 실적 페이스메이커 (★AI)

  • 뭘 하나: 방송 중 5분마다 목표 페이스 대비 실적을 계산해, 저조하면 Claude가 실시간 대응 멘트(매진임박 자막·추가 혜택 강조)와 함께 MD·PD에게 긴급 알림. 반응 지연으로 인한 매출 손실을 막음.
  • 주의: 5분마다 도니 방송 시간대에만 Active. 실시간은 Slack 권장.
  • 필요한 것: Anthropic 키·방송현황 시트(상품·목표매출·총방송분·경과분·누적매출)

L5 ✅ 방송 D-1 사고방지 체크 (★AI)

  • 뭘 하나: 매일 밤 내일 편성표를 재고·가격세팅·혜택·협력사 물량·자막 준비와 대조해, 미비 항목만 담당자에게 알림. "하나 빠뜨려 방송 사고"를 예방. (미비 판정은 규칙 기반, 조치 안내는 Claude가 작성)
  • 필요한 것: 내일편성 시트(방송명·예상판매량·현재재고·가격/혜택/물량/자막 여부)

L1 편성표 아침 알림

  • 뭘 하나: 매일 아침 편성표를 읽어 방송별 담당자에게 자동 메일. (가장 기본형 — 첫 실습에 좋음)

L5 경쟁 홈쇼핑 편성 모니터링 (★AI)

  • 뭘 하나: 경쟁사 오늘 편성(시트에 입력)을 Claude가 카테고리·시간대로 요약 + 우리 차별화 슬롯 제안. (무단 크롤링 대신 시트 기반 — robots 안전)

📞 CS · 콜센터 · 품질이라면

L5 🔁 반품 사유 AI 분류 → 상품개선 루프 (★AI)

  • 뭘 하나: 반품 데이터를 Claude가 사유 분류(사이즈·품질·오배송·변심)하고, 특정 상품의 반복 이슈를 감지해 MD·품질팀에 알림. 쌓이기만 하던 VOC를 상품개선으로 연결.
  • 필요한 것: Anthropic 키·반품데이터 시트(상품명·반품사유)

L4 고객 리뷰 VOC AI 분류 (★AI)

  • 뭘 하나: 신규 리뷰를 Claude가 긍/부정 분류해 부정만 담당팀에 알림.

L4 CS 문의 AI 분류·요약 (★AI)

  • 뭘 하나: 고객 문의(웹훅 수신)를 Claude가 카테고리 분류·요약해 시트에 기록. (웹훅 필드: message · Active 켜려면 AI키+Sheets 둘 다 연결)

L5 📞 콜센터 폭주 조기경보 (★AI)

  • 뭘 하나: 콜 대기·포기율이 임계를 넘으면 Claude 조치 제안(상담 증원·ARS 유도)과 함께 운영팀에 긴급 경보. 콜포기=매출손실을 조기 인지.

🛒 공통 · 매출/재고/주문 (기본형)

L1 방송 실적 리포트

매일 방송 종료 후 매출 시트를 방송별로 집계해 담당 MD에게 메일.

L2 일일매출 집계 다중발송

일일매출을 상품군별로 집계해 담당자 + 팀장에게 동시 발송.

L2 재고 부족 알림

재고가 임계 이하인 상품을 골라 구매담당에게 발주 알림.

L1 신규 주문 알림

주문 수신(웹훅) 즉시 담당자에게 알림 메일. (웹훅 필드: order_id·product·amount)

L3 경쟁사 가격 모니터링

경쟁사 상품 페이지를 매일 확인해 우리보다 싸지면 MD에게 알림. ⚠️ 대상 사이트 robots·약관 확인 필수(무단 크롤링 주의) — 가격 비교는 실무 「가격경쟁력 진단」(네이버 공식 API)이 더 안전·정확하니 그쪽을 권장.

L4 홈쇼핑 뉴스 아침 브리핑 (★AI)

홈쇼핑·유통 뉴스 RSS를 Claude가 3줄 브리핑해 아침에 발송. (실무 「업계 트렌드 브리핑」의 간단 버전)

L5 업계 트렌드·신상품 브리핑 (★AI)

홈쇼핑·유통 뉴스를 Claude가 경쟁사 신상품·트렌드·소싱 힌트로 요약해 MD에게.

어떻게 시작하나 (3단계)

  1. 위에서 내 업무에 가까운 것 1개 고르기 (없으면 "기본형"에서)
  2. 강의 사이트에서 해당 zip 다운로드 → n8n import
  3. YOUR_... 교체(시트·수신자) + 자격증명 연결 → 노드별 Execute step로 검증 → 본인 업무에 맞게 확장

⭐ = 특히 추천 · ★AI = 회사 Anthropic 키 필요(그 외는 Google 크리덴셜만) · 전부 실제 n8n import 검증됨.
