02. 경쟁 홈쇼핑 편성 모니터링

경쟁사 오늘 편성(시트 입력)을 Claude가 카테고리·시간대로 요약하고 우리 차별화 슬롯을 제안합니다. (무단 크롤링 대신 시트 기반)

받는 사람: MD · 분류: 경쟁사 조사 · 시트: 경쟁사편성 탭 헤더: 채널 · 시간 · 상품 · 카테고리

처음 만드는 필드 종류(노드 추가·연결·표현식 토글·크리덴셜)는 공통 조작법을 먼저 보세요.

노드 순서 (총 5개): 매일 08:00 → 경쟁사 편성 읽기 → 채널별 편성 묶기 → Claude 편성 브리핑 → MD 편성 브리핑

Step 1 — 매일 08:00 추가

  • 검색어: Schedule Trigger
  • 속성 설정: Trigger Interval → Days 선택 → Hour = 8, Minute = 00 (n8n 인스턴스 타임존이 이미 Asia/Seoul이면 이게 곧 한국시간입니다 — 1일차 설치 때 GENERIC_TIMEZONE=Asia/Seoul로 띄운 그 설정)
  • 연결: 이 노드가 시작점입니다(입력 연결 없음).

Step 2 — 경쟁사 편성 읽기 추가

  • 검색어: Google Sheets
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Google 계정 선택
    • Resource = Sheet Within Document (기본값)
    • Operation = Get Row(s) (기본값, 바꿀 필요 없음)
    • Document → By URL 또는 By ID → 본인 구글시트 ID 붙여넣기 (원본엔 YOUR_GOOGLE_SHEET_ID 자리)
    • Sheet → 경쟁사편성 탭 선택 (드롭다운에 없으면 gid=0으로 첫 탭 지정)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 3 — 채널별 편성 묶기 추가

  • 검색어: Code
  • 속성 설정: Mode = Run Once for All Items (기본값, 바꾸지 않음) → JavaScript 편집창에 아래 코드를 그대로 붙여넣기:
const items=$input.all();
const by={};
for(const it of items){const ch=it.json['채널']||'경쟁사';(by[ch]=by[ch]||[]).push(`${it.json['시간']||''} ${it.json['상품']||''} (${it.json['카테고리']||''})`);}
const brief=Object.entries(by).map(([k,v])=>`[${k}]\n`+v.join('\n')).join('\n\n');
return [{json:{brief}}];
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 눌러서 출력 JSON에 기대한 필드(위 코드의 return에 있는 키들)가 정확히 나오는지 확인하세요. 여기서 필드명 오타가 나면 다음 노드부터 전부 빈 값이 됩니다.

Step 4 — Claude 편성 브리핑 추가

  • 검색어: HTTP Request
  • 속성 설정:
    • Method = POST
    • URL = https://api.anthropic.com/v1/messages
    • Authentication = Generic Credential Type → Generic Auth Type = Header Auth → Credential = 공통 조작법에서 만든 x-api-key 크리덴셜 선택
    • Send Headers = On → Add Header 2번:
      • anthropic-version = 2023-06-01
      • content-type = application/json
    • Send Body = On → Body Content Type = JSON → Specify Body = Using JSON → 필드의 표현식 토글(=) 켜고 아래를 그대로 붙여넣기:
{{ JSON.stringify({ model: 'claude-sonnet-5', max_tokens: 600, messages: [{ role: 'user', content: '경쟁 홈쇼핑들의 오늘 편성 목록이다(채널·시간·상품·카테고리). 카테고리 분포와 시간대 특징을 3줄로 요약하고, 우리가 차별화할 슬롯 아이디어 2가지를 제안해줘.\n' + $json['brief'] }] }) }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 content[0].text에 Claude의 응답 문장이 들어있는지 확인. invalid x-api-key 에러면 크리덴셜 값을 다시 확인하세요.

Step 5 — MD 편성 브리핑 추가

  • 검색어: Gmail
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Gmail 계정 선택
    • Operation = Send (기본값)
    • To: 표현식 토글 끄고 → YOUR_MD@example.com (본인 이메일로 교체해서 테스트)
    • Subject: 표현식 토글(=) 켜고 → [경쟁편성] 오늘 경쟁 홈쇼핑 편성 브리핑
    • Email Type = Text
    • Message: 표현식 토글(=) 켜고 →
{{ $json.content[0].text }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

✅ 완성 후 테스트: 트리거 노드에서 Test step(또는 Execute Workflow) → 마지막 노드까지 전부 초록불이 뜨는지 확인. 안 뜨면 그 노드를 더블클릭해 에러 메시지를 읽고, 표현식 토글(=)이 켜져 있는지부터 확인하세요.
