01. ⏱ 생방송 실적 페이스메이커

방송 중 5분마다 목표 페이스 대비 실적을 계산해 저조하면 Claude가 실시간 대응 멘트와 함께 긴급 알림을 보냅니다.

받는 사람: MD·PD · 분류: 방송 운영 · 시트: 방송현황 탭 헤더: 상품명 · 목표매출 · 총방송분 · 경과분 · 누적매출

처음 만드는 필드 종류(노드 추가·연결·표현식 토글·크리덴셜)는 공통 조작법을 먼저 보세요.

노드 순서 (총 6개): 방송 중 5분마다 → 현재 방송실적 읽기 → 목표 페이스 계산 → 저조할 때만 → Claude 실시간 대응멘트 → MD·PD 긴급 알림

Step 1 — 방송 중 5분마다 추가

  • 검색어: Schedule Trigger
  • 속성 설정: Trigger Interval → Minutes 선택 → Minutes Between Triggers = 5
  • 연결: 이 노드가 시작점입니다(입력 연결 없음).

Step 2 — 현재 방송실적 읽기 추가

  • 검색어: Google Sheets
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Google 계정 선택
    • Resource = Sheet Within Document (기본값)
    • Operation = Get Row(s) (기본값, 바꿀 필요 없음)
    • Document → By URL 또는 By ID → 본인 구글시트 ID 붙여넣기 (원본엔 YOUR_GOOGLE_SHEET_ID 자리)
    • Sheet → 방송현황 탭 선택 (드롭다운에 없으면 gid=0으로 첫 탭 지정)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 3 — 목표 페이스 계산 추가

  • 검색어: Code
  • 속성 설정: Mode = Run Once for All Items (기본값, 바꾸지 않음) → JavaScript 편집창에 아래 코드를 그대로 붙여넣기:
const r=$json;
const num=v=>Number(String(v||0).replace(/[,\s]/g,''))||0;
const 목표=num(r['목표매출']);
const 총분=num(r['총방송분'])||60;
const 경과=num(r['경과분']);
const 누적=num(r['누적매출']);
const 예상=총분>0?목표*(경과/총분):0;
const 달성률=예상>0?Math.round(누적/예상*100):100;
return [{json:{상품명:r['상품명'],목표,누적,경과분:경과,달성률,저조:String(달성률<80)}}];
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 눌러서 출력 JSON에 기대한 필드(위 코드의 return에 있는 키들)가 정확히 나오는지 확인하세요. 여기서 필드명 오타가 나면 다음 노드부터 전부 빈 값이 됩니다.

Step 4 — 저조할 때만 추가

  • 검색어: If
  • 속성 설정: Add Condition 클릭 →
    • 왼쪽 값(Value): 표현식 토글(=) 켜고 → {{ $json['저조'] }}
    • 연산자(Operator): 문자열 › is equal to (같다)
    • 오른쪽 값(Value): true
  • 동작 방식: If는 조건에 따라 출력이 True/False 두 갈래로 갈립니다. 이 템플릿에서는 True 쪽 출력만 다음 노드에 연결하세요(False는 그냥 끝).
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 5 — Claude 실시간 대응멘트 추가

  • 검색어: HTTP Request
  • 속성 설정:
    • Method = POST
    • URL = https://api.anthropic.com/v1/messages
    • Authentication = Generic Credential Type → Generic Auth Type = Header Auth → Credential = 공통 조작법에서 만든 x-api-key 크리덴셜 선택
    • Send Headers = On → Add Header 2번:
      • anthropic-version = 2023-06-01
      • content-type = application/json
    • Send Body = On → Body Content Type = JSON → Specify Body = Using JSON → 필드의 표현식 토글(=) 켜고 아래를 그대로 붙여넣기:
{{ JSON.stringify({ model: 'claude-sonnet-5', max_tokens: 350, messages: [{ role: 'user', content: '홈쇼핑 생방송이 목표 페이스보다 저조하다. 즉시 쓸 실시간 대응 2가지를 각 한 문장으로 제안해줘(예: 매진임박·수량한정 자막, 방송한정 추가 사은품 언급, 무이자 강조). 방송 진행자가 바로 읽을 수 있는 멘트로.\n상품: ' + $json['상품명'] + ' / 현재 목표 대비 달성률: ' + $json['달성률'] + '% / 경과 ' + $json['경과분'] + '분' }] }) }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 content[0].text에 Claude의 응답 문장이 들어있는지 확인. invalid x-api-key 에러면 크리덴셜 값을 다시 확인하세요.

Step 6 — MD·PD 긴급 알림 추가

  • 검색어: Gmail
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Gmail 계정 선택
    • Operation = Send (기본값)
    • To: 표현식 토글 끄고 → YOUR_MDPD@example.com (본인 이메일로 교체해서 테스트)
    • Subject: 표현식 토글(=) 켜고 → [생방송] {{ $('목표 페이스 계산').item.json['상품명'] }} 목표 대비 {{ $('목표 페이스 계산').item.json['달성률'] }}% 저조
    • Email Type = Text
    • Message: 표현식 토글(=) 켜고 →
⚠️ 생방송 실적 저조
- 상품: {{ $('목표 페이스 계산').item.json['상품명'] }}
- 목표 대비: {{ $('목표 페이스 계산').item.json['달성률'] }}% (경과 {{ $('목표 페이스 계산').item.json['경과분'] }}분)

[실시간 대응 멘트]
{{ $json.content[0].text }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

✅ 완성 후 테스트: 트리거 노드에서 Test step(또는 Execute Workflow) → 마지막 노드까지 전부 초록불이 뜨는지 확인. 안 뜨면 그 노드를 더블클릭해 에러 메시지를 읽고, 표현식 토글(=)이 켜져 있는지부터 확인하세요.
