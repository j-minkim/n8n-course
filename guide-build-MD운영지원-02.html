02. ✅ 방송 D-1 사고방지 체크

매일 밤 내일 편성표를 재고·가격·혜택·물량·자막과 대조해 미비 항목만 Claude 조치안내와 함께 담당자에게 알립니다.

받는 사람: 방송 담당자 · 분류: MD·운영 지원 · 데이터 파일: 내일편성.csv 헤더: 방송명 · 예상판매량 · 현재재고 · 가격설정여부 · 혜택설정여부 · 물량확정여부 · 자막준비여부 (여부 칸은 Y/완료 등) — ~/.n8n-files에 넣기

처음 만드는 필드 종류(노드 추가·연결·표현식 토글·크리덴셜)는 공통 조작법을 먼저 보세요.

🤖 경로 A — Claude Code에게 시키기 (메타프롬프트)

이 강의의 방식대로, 아래 프롬프트를 Claude Code에 그대로 붙여넣으면 이 워크플로 JSON을 만들어줍니다(n8n-MCP 연결 시 더 정확). 받은 JSON을 ⋮ → Import from File로 불러온 뒤 노드별 Test step으로 검증하세요 — AI 초안은 가설, 진실은 에디터 실행 결과입니다.

n8n 워크플로 JSON을 만들어줘: "방송 D-1 사고방지 체크" 자동화야. (데이터는 CSV 파일 기준)

[목표] 매일 밤 내일 편성을 재고·가격·혜택·물량·자막과 대조해, 미비 항목만 Claude 조치안내와 함께 담당자에게 메일.

[노드 체인 — 7개]
1. Schedule Trigger — 매일 20:00
2. Read/Write Files from Disk — 읽기: YOUR_DATA_DIR/내일편성.csv (헤더: 방송명·예상판매량·현재재고·가격설정여부·혜택설정여부·물량확정여부·자막준비여부)
3. Extract from File — CSV 파싱. ★노드 이름 '내일 편성 읽기'
4. Code — 미비 판정: 숫자화 후 현재재고<예상판매량이면 "재고 부족",
   여부 칸(Y/y/O/예/완료/true/1 허용)이 아니면 각각 "가격 미설정"/"혜택 미설정"/"협력사 물량 미확정"/"자막 미준비".
   방송명·미비수·미비목록(" / "로 join, 없으면 "없음") 반환. (노드 이름 '항목별 미비 판정')
5. IF — 미비수 > 0 일 때만
6. HTTP Request(POST) — Claude에게 "담당자가 오늘 밤 처리할 수 있게 우선순위를 매긴 조치 안내를 불릿으로" 요청. 방송명·미비목록 포함.
7. Gmail — 담당자에게: 제목 "[방송 D-1] {방송명} 준비 미비 {미비수}건",
   본문 = 미비 목록 + [조치 안내] Claude 응답. ($('항목별 미비 판정')로 앞 노드 값 참조)

[공통 규칙 — 그대로 지켜줘]
- n8n-MCP가 연결돼 있으면 각 노드의 정확한 파라미터를 조회해서 만들고, 없으면 표준 노드 구조로.
- 데이터는 CSV 파일 기준: 경로는 YOUR_DATA_DIR/… 플레이스홀더로.
  (self-host n8n은 ~/.n8n-files 안의 파일만 접근 가능 — 사용자가 절대경로로 교체할 것)
- Claude 호출은 HTTP Request 노드로: POST https://api.anthropic.com/v1/messages,
  인증은 Header Auth 크리덴셜(이름 x-api-key), 추가 헤더 anthropic-version: 2023-06-01,
  모델 claude-sonnet-5, 응답 본문은 content[0].text 로 파싱.
- 수신자 이메일은 YOUR_...@example.com 플레이스홀더로.
- connections의 타입은 전부 "main". IF 노드는 true 출력만 다음 노드로.
- 완성되면 워크플로 JSON을 파일로 저장해줘 — 내가 n8n에서 ⋮ → Import from File 로 불러올게.
- import 후엔 노드별 Test step으로 하나씩 검증할 거야(통째로 맞다고 가정하지 말 것).

🗂 이 프롬프트는 기본(파일 버전) 기준입니다. 팀 공유용 구글시트 버전(보조)이 필요하면 파일 버전 가이드 §4의 시트 변환 단락을 덧붙이세요.

🔧 경로 B — 손으로 직접 만들기 (스텝바이스텝)

노드가 왜 이 순서로 놓이는지 이해하려면 이 경로로. 아래 Step은 기본(파일 버전) 기준입니다 — 구글시트 버전(보조)은 파일 노드 2단 자리에 Google Sheets 노드 1개가 들어갑니다: 차이 보기

노드 순서 (총 7개): 매일 20:00 (방송 D-1) → 내일편성 파일 읽기 → 내일 편성 읽기 → 항목별 미비 판정 → 미비 있을 때만 → Claude 조치 안내 → 담당자 사고방지 알림

Step 1 — 매일 20:00 (방송 D-1) 추가

  • 검색어: Schedule Trigger
  • 속성 설정: Trigger Interval → Days 선택 → Hour = 20, Minute = 00 (n8n 인스턴스 타임존이 이미 Asia/Seoul이면 이게 곧 한국시간입니다 — 1일차 설치 때 GENERIC_TIMEZONE=Asia/Seoul로 띄운 그 설정)
  • 연결: 이 노드가 시작점입니다(입력 연결 없음).

Step 2 — 내일편성 파일 읽기 추가

  • 검색어: Read/Write Files from Disk
  • 속성 설정:
    • Operation = Read File(s) From Disk (기본값)
    • File(s) Selector = YOUR_DATA_DIR/내일편성.csv → YOUR_DATA_DIR를 본인 ~/.n8n-files 절대경로로 교체
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 출력에 파일이 바이너리(data)로 잡히는지 확인. 파일이 없거나 허용 폴더 밖이면 여기서 에러.

Step 3 — 내일 편성 읽기 추가

  • 검색어: Extract from File
  • 속성 설정: Operation = Extract From CSV → Options → Exclude Byte Order Mark (BOM) 켜기(엑셀이 저장한 CSV 대응 · 엑셀 파일 자체면 Extract From XLSX)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 CSV 각 행이 JSON 아이템으로 나오는지(헤더 = 필드명) 확인 — 여기서부터는 시트 버전과 데이터 모양이 완전히 같습니다.

Step 4 — 항목별 미비 판정 추가

  • 검색어: Code
  • 속성 설정: Mode = Run Once for All Items (기본값, 바꾸지 않음) → JavaScript 편집창에 아래 코드를 그대로 붙여넣기:
const r=$json;
const num=v=>Number(String(v||0).replace(/[,\s]/g,''))||0;
const yes=v=>['Y','y','O','o','예','완료','TRUE','true',true,1].includes(v);
const miss=[];
if(num(r['현재재고'])<num(r['예상판매량'])) miss.push(`재고 부족(재고 ${r['현재재고']} < 예상판매 ${r['예상판매량']})`);
if(!yes(r['가격설정여부'])) miss.push('가격 미설정');
if(!yes(r['혜택설정여부'])) miss.push('혜택 미설정');
if(!yes(r['물량확정여부'])) miss.push('협력사 물량 미확정');
if(!yes(r['자막준비여부'])) miss.push('자막 미준비');
return [{json:{방송명:r['방송명'],미비수:miss.length,미비:miss.join(' / ')||'없음'}}];
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 눌러서 출력 JSON에 기대한 필드(위 코드의 return에 있는 키들)가 정확히 나오는지 확인하세요. 여기서 필드명 오타가 나면 다음 노드부터 전부 빈 값이 됩니다.

Step 5 — 미비 있을 때만 추가

  • 검색어: If
  • 속성 설정: Add Condition 클릭 →
    • 왼쪽 값(Value): 표현식 토글(=) 켜고 → {{ $json['미비수'] }}
    • 연산자(Operator): 숫자 › is greater than (크다)
    • 오른쪽 값(Value): 0
  • 동작 방식: If는 조건에 따라 출력이 True/False 두 갈래로 갈립니다. 이 템플릿에서는 True 쪽 출력만 다음 노드에 연결하세요(False는 그냥 끝).
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 6 — Claude 조치 안내 추가

  • 검색어: HTTP Request
  • 속성 설정:
    • Method = POST
    • URL = https://api.anthropic.com/v1/messages
    • Authentication = Generic Credential Type → Generic Auth Type = Header Auth → Credential = 공통 조작법에서 만든 x-api-key 크리덴셜 선택
    • Send Headers = On → Add Header 2번:
      • anthropic-version = 2023-06-01
      • content-type = application/json
    • Send Body = On → Body Content Type = JSON → Specify Body = Using JSON → 필드의 표현식 토글(=) 켜고 아래를 그대로 붙여넣기:
{{ JSON.stringify({ model: 'claude-sonnet-5', max_tokens: 500, thinking: { type: 'disabled' }, messages: [{ role: 'user', content: '내일 홈쇼핑 방송 준비 점검에서 아래 미비 항목이 나왔다. 담당자가 오늘 밤 처리할 수 있게 우선순위를 매겨 조치 안내를 한국어 불릿으로 정리해줘.\n방송: ' + $json['방송명'] + ' / 미비: ' + $json['미비'] }] }) }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 content[0].text에 Claude의 응답 문장이 들어있는지 확인. invalid x-api-key 에러면 크리덴셜 값을 다시 확인하세요.

Step 7 — 담당자 사고방지 알림 추가

  • 검색어: Gmail
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Gmail 계정 선택
    • Operation = Send (기본값)
    • To: 표현식 토글 끄고 → YOUR_STAFF@example.com (본인 이메일로 교체해서 테스트)
    • Subject: 표현식 토글(=) 켜고 → [방송 D-1] {{ $('항목별 미비 판정').item.json['방송명'] }} 준비 미비 {{ $('항목별 미비 판정').item.json['미비수'] }}건
    • Email Type = Text
    • Message: 표현식 토글(=) 켜고 →
■ {{ $('항목별 미비 판정').item.json['방송명'] }} 내일 방송 준비 미비
{{ $('항목별 미비 판정').item.json['미비'] }}

[조치 안내]
{{ $json.content[0].text }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

✅ 완성 후 테스트: 트리거 노드에서 Test step(또는 Execute Workflow) → 마지막 노드까지 전부 초록불이 뜨는지 확인. 안 뜨면 그 노드를 더블클릭해 에러 메시지를 읽고, 표현식 토글(=)이 켜져 있는지부터 확인하세요.
