01. ⭐ 방송상품 가격경쟁력 진단

방송 예정 상품이 조사해둔 비교가(경쟁몰 가격)보다 비싼지 매일 아침 점검하고, 비싸면 Claude가 방송 대응 소구점을 제안합니다. (파일 버전=외부 API 불필요)

받는 사람: MD · 분류: 경쟁사 조사 · 데이터 파일: 방송예정상품.csv 헤더: 상품명 · 우리방송가 · 비교가격 · 비교몰 — ~/.n8n-files에 넣기

  • ★파일 버전은 외부 API가 필요 없습니다 — CSV의 비교가격(본인이 조사해 입력)과 비교. 실시간 최저가 자동조회(네이버쇼핑 API)는 구글시트 버전(보조)에 있어요(단 네이버 검색 API 2026-07-31 종료 예정).

처음 만드는 필드 종류(노드 추가·연결·표현식 토글·크리덴셜)는 공통 조작법을 먼저 보세요.

🤖 경로 A — Claude Code에게 시키기 (메타프롬프트)

이 강의의 방식대로, 아래 프롬프트를 Claude Code에 그대로 붙여넣으면 이 워크플로 JSON을 만들어줍니다(n8n-MCP 연결 시 더 정확). 받은 JSON을 ⋮ → Import from File로 불러온 뒤 노드별 Test step으로 검증하세요 — AI 초안은 가설, 진실은 에디터 실행 결과입니다.

n8n 워크플로 JSON을 만들어줘: "방송상품 가격경쟁력 진단" 자동화야. (데이터는 CSV 파일 기준 · 외부 API 불필요)

[목표] 방송 예정 상품이 조사해둔 비교가(경쟁몰 가격)보다 비싼지 매일 아침 점검하고, 비싸면 Claude가 방송 대응 소구점을 제안해 MD에게 메일.

[노드 체인 — 7개, 순서대로]
1. Schedule Trigger — 매일 07:30
2. Read/Write Files from Disk — 읽기: YOUR_DATA_DIR/방송예정상품.csv (헤더: 상품명·우리방송가·비교가격·비교몰)
3. Extract from File — CSV 파싱(Exclude BOM 옵션 켜기). ★노드 이름을 '방송예정 상품 읽기'로
4. Code — 비교가격 판단(노드 이름 '비교가격 판단'): 우리방송가·비교가격 숫자화(콤마 제거),
   가격차 = 우리방송가-비교가격, 열위 = (비교가격>0 && 가격차>0) 을 "true"/"false" 문자열로.
5. IF — 열위 = "true" 일 때만
6. HTTP Request(POST) — Claude에게 "비교가보다 비쌀 때 방송에서 쓸 대응 소구점 2가지
   (방송한정가·추가 사은품·무이자·차별화 포인트)"를 3줄로 요청. 상품명·우리방송가·비교가격·비교몰·가격차 포함.
7. Gmail — MD에게: 제목 "[가격경쟁력] {상품명} — 입력 비교가 대비 {가격차}원 비쌈".

★참고: 실시간 최저가 자동조회(네이버쇼핑 API) 버전은 구글시트(보조) 버전에 있어 — 단 네이버 검색 API가 2026-07-31 종료 예정이라, 파일 버전은 의도적으로 "본인이 조사해 입력한 비교가" 방식이야.

[공통 규칙 — 그대로 지켜줘]
- n8n-MCP가 연결돼 있으면 각 노드의 정확한 파라미터를 조회해서 만들고, 없으면 표준 노드 구조로.
- 데이터는 CSV 파일 기준: 경로는 YOUR_DATA_DIR/… 플레이스홀더로.
  (self-host n8n은 ~/.n8n-files 안의 파일만 접근 가능 — 사용자가 절대경로로 교체할 것)
- Claude 호출은 HTTP Request 노드로: POST https://api.anthropic.com/v1/messages,
  인증은 Header Auth 크리덴셜(이름 x-api-key), 추가 헤더 anthropic-version: 2023-06-01,
  모델 claude-sonnet-5, 응답 본문은 content[0].text 로 파싱.
- 수신자 이메일은 YOUR_...@example.com 플레이스홀더로.
- connections의 타입은 전부 "main". IF 노드는 true 출력만 다음 노드로.
- 완성되면 워크플로 JSON을 파일로 저장해줘 — 내가 n8n에서 ⋮ → Import from File 로 불러올게.
- import 후엔 노드별 Test step으로 하나씩 검증할 거야(통째로 맞다고 가정하지 말 것).

🗂 이 프롬프트는 기본(파일 버전) 기준입니다. 팀 공유용 구글시트 버전(보조)이 필요하면 파일 버전 가이드 §4의 시트 변환 단락을 덧붙이세요.

🔧 경로 B — 손으로 직접 만들기 (스텝바이스텝)

노드가 왜 이 순서로 놓이는지 이해하려면 이 경로로. 아래 Step은 기본(파일 버전) 기준입니다 — 구글시트 버전(보조)은 파일 노드 2단 자리에 Google Sheets 노드 1개가 들어갑니다: 차이 보기

노드 순서 (총 7개): 매일 07:30 → 방송예정상품 파일 읽기 → 방송예정 상품 읽기 → 비교가격 판단 → 가격 열위만 → Claude 대응 소구점 → MD 가격진단 메일

Step 1 — 매일 07:30 추가

  • 검색어: Schedule Trigger
  • 속성 설정: Trigger Interval → Days 선택 → Hour = 7, Minute = 30 (n8n 인스턴스 타임존이 이미 Asia/Seoul이면 이게 곧 한국시간입니다 — 1일차 설치 때 GENERIC_TIMEZONE=Asia/Seoul로 띄운 그 설정)
  • 연결: 이 노드가 시작점입니다(입력 연결 없음).

Step 2 — 방송예정상품 파일 읽기 추가

  • 검색어: Read/Write Files from Disk
  • 속성 설정:
    • Operation = Read File(s) From Disk (기본값)
    • File(s) Selector = YOUR_DATA_DIR/방송예정상품.csv → YOUR_DATA_DIR를 본인 ~/.n8n-files 절대경로로 교체
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 출력에 파일이 바이너리(data)로 잡히는지 확인. 파일이 없거나 허용 폴더 밖이면 여기서 에러.

Step 3 — 방송예정 상품 읽기 추가

  • 검색어: Extract from File
  • 속성 설정: Operation = Extract From CSV → Options → Exclude Byte Order Mark (BOM) 켜기(엑셀이 저장한 CSV 대응 · 엑셀 파일 자체면 Extract From XLSX)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 CSV 각 행이 JSON 아이템으로 나오는지(헤더 = 필드명) 확인 — 여기서부터는 시트 버전과 데이터 모양이 완전히 같습니다.

Step 4 — 비교가격 판단 추가

  • 검색어: Code
  • 속성 설정: Mode = Run Once for All Items (기본값, 바꾸지 않음) → JavaScript 편집창에 아래 코드를 그대로 붙여넣기:
const n=v=>Number(String(v??0).replace(/[,\s]/g,''))||0;
const mine=n($json['우리방송가']);
const compare=n($json['비교가격']);
const gap=mine-compare;
return [{json:{상품명:$json['상품명'],우리방송가:mine,비교가격:compare,비교몰:$json['비교몰']||'사용자 입력',가격차:gap,열위:String(compare>0&&gap>0)}}];
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 눌러서 출력 JSON에 기대한 필드(위 코드의 return에 있는 키들)가 정확히 나오는지 확인하세요. 여기서 필드명 오타가 나면 다음 노드부터 전부 빈 값이 됩니다.

Step 5 — 가격 열위만 추가

  • 검색어: If
  • 속성 설정: Add Condition 클릭 →
    • 왼쪽 값(Value): 표현식 토글(=) 켜고 → {{ $json['열위'] }}
    • 연산자(Operator): 문자열 › is equal to (같다)
    • 오른쪽 값(Value): true
  • 동작 방식: If는 조건에 따라 출력이 True/False 두 갈래로 갈립니다. 이 템플릿에서는 True 쪽 출력만 다음 노드에 연결하세요(False는 그냥 끝).
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 6 — Claude 대응 소구점 추가

  • 검색어: HTTP Request
  • 속성 설정:
    • Method = POST
    • URL = https://api.anthropic.com/v1/messages
    • Authentication = Generic Credential Type → Generic Auth Type = Header Auth → Credential = 공통 조작법에서 만든 x-api-key 크리덴셜 선택
    • Send Headers = On → Add Header 2번:
      • anthropic-version = 2023-06-01
      • content-type = application/json
    • Send Body = On → Body Content Type = JSON → Specify Body = Using JSON → 필드의 표현식 토글(=) 켜고 아래를 그대로 붙여넣기:
{{ JSON.stringify({ model: 'claude-sonnet-5', max_tokens: 400, thinking: { type: 'disabled' }, messages: [{ role: 'user', content: '홈쇼핑 방송 상품의 가격 경쟁력 진단이다. 아래 정보를 보고, 사용자 입력 비교가보다 비쌀 때 방송에서 쓸 대응 소구점 2가지(예: 방송한정가·추가 사은품·무이자·차별화 포인트)를 한국어 3줄로 제안해줘.\n상품: ' + $json['상품명'] + ' / 우리 방송가: ' + $json['우리방송가'] + '원 / 사용자 입력 비교가: ' + $json['비교가격'] + '원(' + $json['비교몰'] + ') / 가격차: ' + $json['가격차'] + '원' }] }) }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 content[0].text에 Claude의 응답 문장이 들어있는지 확인. invalid x-api-key 에러면 크리덴셜 값을 다시 확인하세요.

Step 7 — MD 가격진단 메일 추가

  • 검색어: Gmail
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Gmail 계정 선택
    • Operation = Send (기본값)
    • To: 표현식 토글 끄고 → YOUR_MD@example.com (본인 이메일로 교체해서 테스트)
    • Subject: 표현식 토글(=) 켜고 → [가격경쟁력] {{ $('비교가격 판단').item.json['상품명'] }} — 입력 비교가 대비 {{ $('비교가격 판단').item.json['가격차'] }}원 비쌈
    • Email Type = Text
    • Message: 표현식 토글(=) 켜고 →
■ {{ $('비교가격 판단').item.json['상품명'] }}
- 우리 방송가: {{ $('비교가격 판단').item.json['우리방송가'] }}원
- 사용자 입력 비교가: {{ $('비교가격 판단').item.json['비교가격'] }}원 ({{ $('비교가격 판단').item.json['비교몰'] }})
- 가격차: {{ $('비교가격 판단').item.json['가격차'] }}원

[대응 소구점 제안]
{{ $json.content[0].text }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

✅ 완성 후 테스트: 트리거 노드에서 Test step(또는 Execute Workflow) → 마지막 노드까지 전부 초록불이 뜨는지 확인. 안 뜨면 그 노드를 더블클릭해 에러 메시지를 읽고, 표현식 토글(=)이 켜져 있는지부터 확인하세요.
