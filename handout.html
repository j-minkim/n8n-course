1. self-host 설치 (각자 노트북 · ★Docker 없이 · Claude Code 주도)

💡 명령어를 외울 필요 없어요 — Claude Code가 설치를 대신 다 해줍니다. "내 컴퓨터에 n8n 설치해줘" 한마디면 Node 확인 → npx n8n 실행 → 기동 대기 → 접속 안내 → 에러 해결까지 설치 전 과정을 진행해요. 여러분이 직접 할 건 브라우저 열기·계정 입력·시스템 설치 승인 셋뿐.

Claude Code에게 그대로 부탁: "내 컴퓨터에 n8n 설치해서 띄워줘. 타임존 Asia/Seoul, Docker 말고 npx로." Claude Code가 하는 일:

node -v                                  # Node 20.19~24.x 확인 (없으면 nvm 안내)
GENERIC_TIMEZONE=Asia/Seoul npx n8n      # 첫 실행은 1~5분 다운로드(정상)

→ 브라우저 http://localhost:5678 → Setup Wizard에 이메일·비번 입력 = Owner.

  • 데이터는 ~/.n8n에 저장 — 껐다 켜도 유지(Docker 볼륨 불필요). 백업=폴더 복사.
  • 막히면: 에러 메시지를 Claude Code에 그대로 붙여넣어 함께 해결("같이 디버깅하는 파트너").
  • 흔한 막힘: EACCES→sudo 금지·nvm / Node 버전 안 맞음→nvm 전환 / 포트충돌→N8N_PORT=8080.
  • Claude Code가 못 하는 것: 브라우저 열기·Owner 정보 입력·Node 설치 승인은 내가.
  • ⚠️ Node 범위·npx 동작·Wizard UI는 버전 따라 변동 — 강사가 당일 확인.

2. 무엇을 자동화할지 먼저 (brainstorming PRD)

/superpowers:brainstorming → 질문 하나씩 답하며 자동화 PRD 5섹션:

  1. 트리거(언제) 2. 입력(무엇을) 3. 처리(변환·AI 판단) 4. 출력(어디로) 5. 예외·한도(실패·재시도·비용·개인정보) → ★PRD 승인 전엔 워크플로 안 만든다(HARD-GATE). PRD가 명확해야 AI도 맞는 노드를 만든다.

3. PRD → n8n 6레이어

트리거 / 수집 / 가공 / AI 판단 / 액션·알림 / 에러핸들링.

4. AI-native 빌드 (Claude Code + n8n-MCP)

  • n8n-MCP 연결(터미널 1회): claude mcp add n8n-mcp -e MCP_MODE=stdio -e LOG_LEVEL=error -e DISABLE_CONSOLE_OUTPUT=true -- npx n8n-mcp → Claude Code 재시작 → claude mcp list 에 n8n-mcp ✔ Connected. (윈도우 PowerShell은 각 -e 따옴표 / API 키 없이 노드 조회·검증 가능)
  • n8n-MCP로 정확한 노드명·파라미터 조회(환각↓).
  • ★노드별 순차 빌드 + 즉시 실행·검증. 거대 JSON 한 번에 만들면 줄줄이 에러.
  • 표현식 함정: {{ $json.email }}(접두사)·노드명 대소문자("HTTP Request"). → 에디터 실행으로 확인.
  • 워크플로 import: 에디터 ⋮ → Import from File/URL.

5. AI 노드 핸즈온

n8n Anthropic Chat Model → Credentials에 회사 제공 API 키 → CS 문의 분류/요약. (개인 Pro로는 안 됨)

6. self-host는 공짜가 아니다

업데이트(npx 실습자=npx --yes n8n@latest, global 설치자=npm update -g n8n)·백업(~/.n8n 폴더 복사 = database.sqlite+config 세트)·보안을 직접 책임. "로컬 체험"과 "사내 24시간 운영"은 다르다 — 후자는 사내 IT와(이때는 Docker도 한 방법).

🔒 보안·버전 고정: 운영은 npx n8n@1.xx.x로 버전 고정(매번 최신 X)해 재현성·공급망 관리. ⚠️"소스 zip으로 설치가 더 안전"은 오해 — 같은 npm 의존성, 빌드만 복잡. 네트워크(HTTPS·인증)·암호화 키(N8N_ENCRYPTION_KEY)·백업은 47-selfhost-보안-가이드.md 참고.
