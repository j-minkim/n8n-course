n8n 자동화 강의 — 인쇄용 핸드아웃 (2일 · 16h)

이 한 장(묶음)만 들고 다니세요. 슬라이드(40-courseware-day1/2.html)의 핵심을 인쇄용으로 압축한 요약 + 실습 단계 포인터 + 사전준비 체크리스트 + (강사용) 매 기수 라이브 재확인 페이지입니다.

딱 하나만 기억할 구분: Claude 구독(claude.ai 챗) → 설계·디버깅 보조용, 회사가 제공한 Anthropic API 키 → n8n 워크플로 안의 AI 노드를 실제로 돌리는 것. 둘은 다른 것입니다.

1. 인쇄용 강의 요약

1.0 이 강의가 끝나면 (학습목표)

  • LO1 (이해) 트리거·액션·노드·워크플로 개념 + n8n Cloud vs self-host + Claude 구독 vs Anthropic API 키 를 내 말로 구분한다.
  • LO2 (적용) 스케줄 → 구글시트 읽기 → 메일 발송 기본 워크플로(노드 2~3개)를 직접 만들어 실행한다.
  • LO3 (적용·분석) IF·Filter 조건분기 + 데이터 처리·다중출력(여러 시트/여러 수신자)을 설계·구현한다.
  • LO4 (적용) 설계 템플릿으로 복합 워크플로(주간 성과 리포트) + 에러 핸들링을 구성한다.
  • LO4b (적용) Basic LLM Chain + Anthropic Chat Model(서브노드, 회사 API 키) 로 CS 문의를 분류/요약해 시트·메일에 연동한다(수강생 직접 핸즈온).
  • LO5 (창조+평가) 내 업무 반복작업을 발견·설계해 자동화 미니프로젝트를 만들고 시연하며 동료를 비평한다.

1.1 핵심 개념 한눈에

개념 한 줄 정의 예시
트리거 (Trigger) 흐름을 시작시키는 사건 Schedule Trigger(매일 09:00), Webhook(외부 호출)
액션 (Action) 실제로 일을 수행하는 노드 Google Sheets 행 추가, Gmail 발송
노드 (Node) 하나의 블록(트리거도 액션도 노드) 노드 1개 = 한 가지 일
조건분기 (Branch) 조건에 따라 갈라짐 IF(두 갈래 true/false), Filter(통과만 남김)
표현식 매핑 앞 노드 데이터를 꺼내 쓰기 {{ $json.상품군 }} · 한글/공백 필드는 {{ $json["상품군"] }}
다중출력 하나의 결과를 여러 곳으로 집계 1건 → 요약 시트 + 메일 2곳
에러 핸들링 실패에 대비 Error Trigger(실패 시 별도 흐름) · Stop And Error(의도적 멈춤) · Executions(실행 로그)

1.2 자동화 좋은 일 vs 어려운 일

  • 좋은 일: 매일/매주 반복 + 규칙이 분명(언제·무엇을·어디로) + 데이터 기반(편성표→메일, 매출 집계→리포트).
  • 어려운 일: 매번 다른 판단·협상·창작, 규칙이 모호/예외 다수, 정형화되지 않은 입력.
  • 단, "규칙이 분명한 자연어 분류"(예: CS 문의를 배송/환불로)는 AI 노드로 자동화 가능(LO4b).

1.3 내려놓을 3가지 오해

  1. "자동화 = 코딩이라 못 한다" → n8n은 노드를 화면에서 연결(코딩 0줄, 표현식만 약간).
  2. "한 번 만들면 끝" → 데이터·계정·정책은 바뀐다 → 에러 핸들링·로그 확인 필수.
  3. "툴이 알아서 다 한다" → 무엇을·언제(트리거)·어디로(매핑) 는 내가 설계. 엑셀 매크로와 다름.

1.4 환경 사실 (검증됨 · 외워둘 것)

  • 실습 환경 = n8n Cloud(매니지드). 가입 → 바로 시작. Docker self-host는 실습 X, 참고 문서로만(46-selfhost-가이드.md).
  • Cloud 플랜: 실습 = Starter / Pro(Hosted by n8n). Business는 self-host 전용 라이선스. 과금 단위 = 워크플로 실행 1회(스텝 수 무관).
  • 타임존: Cloud는 가입 시 자동 감지, 실패 시 기본 GMT → 반드시 Manage → Timezone = Asia/Seoul (UTC+9) 설정(워크플로별 오버라이드도 가능). self-host 기본은 America/New_York.
  • Claude 구독(claude.ai 챗)은 API 미포함 — 설계·디버깅 보조 전용. 워크플로 AI 노드는 별도 Anthropic API 키(console.anthropic.com) 로만 동작(회사 제공). 2026-06-15 Anthropic 과금 개편은 'API 키 사용'인 n8n 노드엔 무영향.
  • 구글 연동: n8n Cloud는 Managed OAuth2('Sign in with Google') 지원(특정 Google 노드). 사내 정책상 외부 OAuth가 막힐 수 있음 → 사전 확인 / 막히면 공용 데모 시트·수신함으로 대체.
  • Gmail 발송 한도: 무료 500건/일, Workspace 2,000건/일(롤링 24h). 초과 시 발송 오류.
  • 장시간/대량 주의: Cloud Webhook 응답 100초 초과 시 524, 페이로드 기본 16MB. N8N_PAYLOAD_SIZE_MAX는 self-host 전용(Cloud 변경 불가) → 대량 리포트는 분할 처리.

이 템플릿이 2일차 본실습(주간 리포트) 과 내 업무 적용의 공통 뼈대. 외워두면 어떤 업무든 끼워 맞출 수 있습니다.

2. 실습 포인터 (단계 요약 · 자세한 절차는 30-exercises.md)

난이도 사다리 = 워크드예제 → 페이드(빈칸 채우기) → 독립. "실행 녹색"이 성공 신호.

1일차

  • E1 개념 매칭 — "이건 트리거? 액션? / Cloud? self-host? / Claude 구독? API 키?" 분류 퀵체크.
  • E2 표현식 미니실습 — {{ $json.상품군 }} 로 상품군별 group + sum. 흔한 실수: {{ }} 빠뜨려 글자 그대로 출력 / 한글 필드는 ["상품군"] 대괄호 / 필드명 오타 → Schema로 실제 키 확인.
  • Lab1 (LO2) 편성표 → 담당자 메일 — ① Schedule Trigger(Days, 09:00, Asia/Seoul) → ② Google Sheets Get Row(s)(편성표) → ③ Gmail Send({{ $json.방송명 }} 매핑) → ④ Execute, 3노드 녹색 + 받은편지함 메일 1통 = 성공 → Active 토글. 막히면: credential not found → Sign in with Google 또는 공용 데모 시트.
  • Lab2 (LO3) 조건분기 — Sheets 매출 읽기 → IF {{ $json.매출 }} is smaller than {{ $json.목표매출 }} → true 가지에 미달 방송만. 흔한 실수: 매출이 문자열("1,200,000")이면 비교 실패 → 콤마 제거 후 Number 변환.
  • Lab3 (LO3) 다중출력 — 일일 매출 읽기 → 상품군별 합산(하나의 요약 아이템) → Sheets Append(요약 시트) → Gmail Send ×2 이상(담당자 + 팀 메일링리스트). 흔한 실수: 집계 전에 발송하면 행마다 메일 → 먼저 집계.
  • M6 디버깅 — Error Trigger / Stop And Error / Executions(실행 로그) 로 실패 노드 추적. Claude 구독 챗으로 에러 로그 해석 보조(워크플로를 대신 돌리는 건 아님).

2일차 — Lab4 (체크포인트 분할 · 전원 완주 보장)

  • Lab4-전반 / 게이트① (LO4) 집계까지 — ① Schedule(매주 월 08:00, Asia/Seoul) → ② Sheets Get Row(s)(주간 매출) → ③ 상품군별/방송별 집계 → ④ Sheets Append(요약 시트). 게이트①(70분 지점): 요약 시트에 집계값 쓰였고 녹색 실행 → 통과. 미통과 → 강사 검수 후 import 파일 ①.json 불러와 후반부터 합류(시트 ID·Credential 본인 것으로 교체).
  • Lab4-후반 / 게이트② (LO4) 발송·에러 — ⑤ 포맷팅(Edit Fields/Set) → ⑥ 다중발송(팀장 + 메일링리스트) → ⑦ 에러 핸들링(Error Trigger + Stop And Error, 의도적 오류로 검증). 미통과 → import 파일 ②.json 불러와 AI 노드만 마무리.
  • Lab4-AI (LO4b) CS 분류/요약 — 수강생 직접 핸즈온 — ⑧ CS 문의 더미 시트 읽기 → ⑨ Basic LLM Chain 추가(루트) → 프롬프트 입력 "다음 CS 문의를 [배송/환불/상품문의/기타]로 분류하고 한 줄 요약: {{ $json.문의내용 }}" → ⑩ Anthropic Chat Model을 체인의 Chat Model 자리에 연결 + Credential(New → Anthropic API → 회사 제공 키) → 체인 실행 (Chat Model은 단독 실행 안 되는 서브노드 — 체인에 꽂아야 돌아감) → ⑪ 결과를 Sheets/Gmail로 연동. 게이트②(최종): 다중발송 + 에러핸들링 + AI 노드 전부 녹색 + 분류/요약 기록 = 중심 문제 완성. 호출은 필요한 만큼만.
  • E3 / S2 (LO5) 내 업무 미니프로젝트 — 내 반복업무 1개를 6칸 템플릿 표에 채워 → 최소 동작 워크플로 구축 → 2분 시연 + 동료 피드백 1개. 빈 칸 있어도 됨(트리거·수집·알림만으로도 동작).

3. 사전준비 체크리스트

3.1 수강생 (강의 전)

  • 사내 구글 계정 · 사내 메일 로그인 정보 지참(실습 연동용). 사내 PC 외부 접속/설치 권한 확인.
  • 회사 제공 Claude 구독 계정 로그인 확인(설계·디버깅 보조용).
  • 워크플로의 AI 노드는 회사가 제공한 Anthropic API 키로 연결합니다 — 개인 Claude 구독(claude.ai)으로는 동작하지 않습니다. 개인 결제·발급 불필요, 강의 중 직접 n8n Credentials에 입력해 AI 노드 핸즈온.
  • 내 업무에서 "매주/매일 반복하는 작업" 1~2개를 미리 떠올려 오기(미니프로젝트 소재).
  • 코딩 경험 불필요. "자동화=코딩"이라는 오개념 내려놓기.
  • (선수지식) 엑셀/구글시트 기본 사용(읽기·합계·필터).

3.2 강사 (강의 전 리허설·실측)

  • n8n Cloud 계정/실습 환경 준비(트라이얼 또는 유료). Manage → Timezone = Asia/Seoul(UTC+9) 설정 확인.
  • 구글 연동 실측: Sheets·Gmail 노드의 'Sign in with Google'(Managed OAuth2) 노출·동작을 사내 계정에서 1회 확인.
  • 사내 IT/보안 확인: 외부 OAuth 앱(n8n) 연결 허용 여부 + 외부 메일 발송 정책. Gmail 발송 한도(Workspace 2,000/무료 500) 인지.
  • 대체 핸즈온 경로 사전 구축(사내 막힘 대비): ① 공용 데모 구글시트, ② 공용 데모 수신함(테스트 Gmail/캐치올), ③ 강사 공유 Credential 또는 n8n Managed OAuth2. 대체 경로에서도 수강생이 자기 화면에서 직접 노드 조작.
  • 회사 Anthropic API 키 배포 방식 확정(공유 키 1개 vs 수강생별 키 — 회사 정책). 기수당 예상 호출량·크레딧 한도 점검. 비상시(키 미배포·한도 초과) 강사 시연 분기 준비.
  • 데모 자료: 더미 구글시트(편성표·일일/주간 매출·CS 문의 텍스트 더미), 테스트 수신 주소(담당자·팀장·메일링리스트), 완성형 주간 리포트 워크플로 1개, 의도적 오류 워크플로 1개(M6).
  • 중간 완성 import .json 2개 사전 제작·검증: ①(스케줄→매출→집계→요약시트), ②(① + 포맷팅·다중발송·에러핸들링). 실제로 "Import from File" 해서 다음 게이트가 이어지는지 검증.
  • 핸드아웃 문서(실습 아님): Docker self-host 셋업 가이드(46-selfhost-가이드.md), Anthropic API 키 입력(발급 아님) 가이드.
  • 스크린샷 자리표시자 채우기(45-image-spec.md 4개 필수 + 권장 5개): Cloud 캔버스·Lab1 성공·Timezone·Anthropic Credential 등. API Key·실주소 마스킹.
  • 리허설: Lab1·2·3 + Lab4 전·후반 게이트(AI 노드 포함) 를 Cloud에서 처음부터 끝까지 1회 직접 실행.
