1. self-host 설치 (각자 노트북 · ★Docker 없이 · Claude Code 주도)

💡 명령어를 외울 필요 없어요 — Claude Code가 설치를 대신 다 해줍니다. "내 컴퓨터에 n8n 설치해줘" 한마디면 Node 확인 → npx n8n@2.26.8 실행 → 기동 대기 → 접속 안내 → 에러 해결까지 설치 전 과정을 진행해요. 여러분이 직접 할 건 브라우저 열기·계정 입력·시스템 설치 승인 셋뿐.

Claude Code에게 그대로 부탁: "내 컴퓨터에 n8n 설치해서 띄워줘. 타임존 Asia/Seoul, Docker 말고 npx로." Claude Code가 OS에 맞춰 하는 일:

node -v                                  # Node 20.19–24.x 확인
GENERIC_TIMEZONE=Asia/Seoul npx n8n@2.26.8

node -v
$env:GENERIC_TIMEZONE='Asia/Seoul'; npx n8n@2.26.8

→ 브라우저 http://localhost:5678 → Setup Wizard에 이메일·비번 입력 = Owner.

  • 데이터는 ~/.n8n에 저장 — 껐다 켜도 유지(Docker 볼륨 불필요). 로컬 백업은 n8n을 정상 종료한 뒤 ~/.n8n 전체(database.sqlite+config 등)를 복사합니다.
  • 막히면: 에러 메시지를 Claude Code에 그대로 붙여넣어 함께 해결("같이 디버깅하는 파트너").
  • 흔한 막힘: EACCES→sudo 금지·nvm / Node 버전 안 맞음→nvm 전환 / 포트충돌→N8N_PORT=8080.
  • Claude Code가 못 하는 것: 브라우저 열기·Owner 정보 입력·Node 설치 승인은 내가.
  • ⚠️ Node 범위·npx 동작·Wizard UI는 버전 따라 변동 — 강사가 당일 확인.

2. 무엇을 자동화할지 먼저 (경량 스킬 PRD)

/n8n-automation-prd → 5섹션 PRD를 한 번에(비는 칸만 채움) 자동화 PRD 5섹션:

  1. 트리거(언제) 2. 입력(무엇을) 3. 처리(변환·AI 판단) 4. 출력(어디로) 5. 예외·한도(실패·재시도·비용·개인정보) → ★단계 게이트: 설계 확정 → JSON 초안 → 실제 생성(실습 기본 import). 한 번의 OK로 실제 생성까지 가지 않는다. PRD가 명확해야 AI도 맞는 노드를 만든다. 정말 크고 복잡한 설계만 /superpowers:brainstorming.
  • 우리 회사 예시 3개: ⓐ방송 실적 리포트(스케줄·집계) ⓑ경쟁사 가격 모니터링(HTTP·IF) ⓒ고객 리뷰 VOC AI 분류(Anthropic·IF).

3. PRD → n8n 6레이어

트리거 / 수집 / 가공 / AI 판단 / 액션·알림 / 에러핸들링.

오류처리 공식 방식: Error Trigger는 별도 오류 워크플로의 시작 노드입니다. 별도 워크플로를 저장·활성화한 뒤 원본 Settings → Error workflow에서 지정합니다. 데이터가 비었을 때 같은 흐름을 의도적으로 멈추는 것은 Stop And Error입니다.

4. AI-native 빌드 (Claude Code + n8n-MCP)

  • n8n-MCP 연결(터미널 1회): claude mcp add n8n-mcp -e MCP_MODE=stdio -e LOG_LEVEL=error -e DISABLE_CONSOLE_OUTPUT=true -- npx --yes n8n-mcp@2.64.1 → Claude Code 재시작 → claude mcp list 에 n8n-mcp ✔ Connected. (윈도우 PowerShell은 각 -e 따옴표 / API 키 없이 노드 조회·검증 가능)
  • 버전·쿼터 구분: 강의 전 npm view n8n-mcp version으로 최신을 확인해도 실습은 검증된 2.64.1로 고정. 이 로컬 stdio 경로에는 선택형 hosted 무료 티어(현재 100 tool calls/day)가 적용되지 않으며 Claude Code 사용량은 별개입니다.
  • n8n-MCP로 정확한 노드명·파라미터 조회(환각↓).
  • ★노드별 순차 빌드 + 즉시 실행·검증. 거대 JSON 한 번에 만들면 줄줄이 에러.
  • 표현식 함정: {{ $json.email }}(접두사)·노드명 대소문자("HTTP Request"). → 에디터 실행으로 확인.
  • 워크플로 import: 에디터 ⋮ → Import from File/URL.

5. AI 노드 핸즈온

n8n Anthropic Chat Model → Credentials에 본인의 개인 제한 API 키 → CS 문의 분류/요약. (개인 Pro로는 안 됨)

5.5 Lab6 기본 경로

파일(CSV) 템플릿 선택 → Import from File → YOUR_DATA_DIR·입력 CSV 교체 → 노드/출력 1개 확장 → Test step. 파일 버전은 Google OAuth 0개이며, AI·Gmail 자격증명까지 0개라는 뜻은 아닙니다. Google Sheets는 팀 공유가 필요할 때만 보조로 사용합니다.

6. self-host는 공짜가 아니다

업데이트 후보는 npm view n8n version으로 조회만 하고 별도 환경에서 검증한 뒤 고정 버전을 변경합니다. 백업·보안도 직접 책임지며, 로컬 백업은 n8n 정상 종료 후 ~/.n8n 전체(database.sqlite+config 등) 복사, 사내 24시간 운영은 사용 DB별 일관된 스냅샷·백업 절차를 사내 IT와 적용합니다. "로컬 체험"과 운영은 다릅니다(운영에는 Docker도 한 방법).

🔒 보안·버전 고정: 운영은 npx n8n@2.26.8로 버전 고정(매번 최신 X)해 재현성·공급망 관리. ⚠️"소스 zip으로 설치가 더 안전"은 오해 — 같은 npm 의존성, 빌드만 복잡. 네트워크(HTTPS·인증)·암호화 키(N8N_ENCRYPTION_KEY)·백업은 47-selfhost-보안-가이드.md 참고.
