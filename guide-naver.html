네이버 검색 API, 발급해야 하나요?

결론: 아니요 — 이 강의 템플릿 20종 전부 네이버 키 없이 돌아갑니다

1. 왜 필요 없나

원래 「가격경쟁력 진단」이 네이버쇼핑 검색 API로 인터넷 최저가를 자동 조회했지만, 네이버 검색 API가 2026-07-31 종료 예고됐고 후속 플랫폼(NAVER API HUB)에 같은 상품검색 대체 API가 없어서 — 템플릿을 외부 조회 없이 동작하도록 개정했습니다:

  • 파일버전(기본)·시트버전(보조) 모두: 본인이 허용된 비교몰에서 확인한 비교가격·비교몰을 CSV/시트에 입력 → 워크플로가 우리방송가와 비교해 열위 판정 → Claude 대응 소구점
  • 자동 조회가 빠진 대신 곧 죽을 외부 의존이 없고, 비교 기준(어느 몰과 비교할지)을 본인이 통제합니다

즉 크리덴셜 준비물은 그대로 3개뿐: Google(Gmail) · 회사 Anthropic 키 · 그리고 파일버전이면 그마저 Gmail+Anthropic 2개.

2. (부록) 그래도 외부 API 연동을 배워보고 싶다면

"HTTP Request로 외부 API를 물리는 법"은 그 자체로 좋은 연습입니다. 종료일(2026-07-31) 전까지는 네이버 검색 API가 정상 동작하니, 원하면 이렇게:

2-1. 발급 (무료 · 5분 · 개인 계정 OK)

  1. developers.naver.com 로그인 → Products → 서비스 API → 검색
  2. "오픈 API 이용 신청" 클릭 → 애플리케이션 등록:
필드 입력값
애플리케이션 이름 자유 (예: n8n-price-check)
사용 API 검색
비로그인 오픈 API 서비스 환경 WEB 설정
웹 서비스 URL http://localhost:5678
  1. 내 애플리케이션에서 Client ID 확인 · Client Secret은 [보기]로 확인

🔒 개인 인증정보 — 워크북·단톡방 공유 금지.

2-2. n8n에서 호출 (HTTP Request 노드)

  • Method GET · URL: https://openapi.naver.com/v1/search/shop.json?query={{ encodeURIComponent($json['상품명']) }}&display=20&sort=sim
  • Send Headers → X-Naver-Client-Id / X-Naver-Client-Secret = 본인 값 (비로그인 API라 이 헤더 2개가 전부 — OAuth 없음)
  • Test step → items[]에 title·lprice·mallName 보이면 성공

터미널 확인:

curl "https://openapi.naver.com/v1/search/shop.json?query=%EC%95%95%EB%A0%A5%EB%B0%A5%EC%86%A5&display=5" \
  -H "X-Naver-Client-Id: 본인ID" -H "X-Naver-Client-Secret: 본인Secret"

2-3. 한도·막힘

  • 무료 일 25,000회(앱 기준, 전 검색 카테고리 합산) · 호출당 최대 100건 — 실습으론 여유
  • 401 = 헤더 이름/값 오타(대소문자·공백) · 429(errorCode 010) = 일 쿼터 소진, 다음 날 리셋
  • ⚠️ 검색결과엔 부품·액세서리가 섞입니다 — 구 템플릿은 "가격 중앙값의 40% 미만 버림" 휴리스틱으로 걸렀어요(같은 로직을 Code 노드에 넣으면 됨)
  • 막히면 에러 전문을 Claude Code에 붙여넣기

2-4. 종료 이후

2026-07-31 이후엔 이 API가 중단됩니다. 후속은 NAVER API HUB(종량제·통합 키)지만 현재 동일한 상품검색 API는 없어요 — 그래서 커리큘럼 기본은 비교가격 입력 방식입니다.
