n8n 자동화 — 수강생 실습 워크북 (따라하며 채우기)

이건 읽는 자료가 아니라 채우는 자료예요. 손으로 체크박스를 ☑ 하고, 빈칸 ____ 을 직접 적으면서 따라오세요.

  • 개념이 헷갈리면 → 핸드아웃(40-handout.md).
  • 단계가 막히면 → 강사·런북, 또는 이 문서 하단의 "막히면" 안내.
  • 정답은 일부러 비워뒀어요. 빈칸은 스스로 채우는 칸이에요(막히면 강사·런북 참고).

딱 하나만 기억할 구분: Claude 구독(claude.ai 챗) 은 설계·디버깅을 도와주는 보조 도구일 뿐이고, 워크플로 안의 AI 노드는 별도 Anthropic API 키로만 돌아가요. 즉 Claude 구독과 AI 노드용 API 키는 별개예요(자세한 운영 안내는 Lab4-AI 단계에서).

이 표기 약속: 단계마다 구간 라벨이 붙어요 — [워크드] 강사 따라하기 / [페이드] 빈칸 채우기 / [독립] 스스로. 보기 라벨은 A/B/C/D.

0. 시작 전 셀프 점검 (실습 시작 전에 ☑)

본인 화면에서 직접 확인하고 체크하세요. 하나라도 비면 강사에게 손!

환경 로그인

  • n8n Cloud에 로그인 됨(매니지드 — 내가 Docker 깔 필요 없음).
  • 회사 구글 계정 로그인 확인(Sheets·Gmail 연동에 쓸 계정).
  • 회사 Claude 계정(claude.ai 챗) 로그인 확인(설계·디버깅 보조용).
  • 회사 Anthropic API 키를 받았거나, 받는 방법을 안다(Lab4 AI 노드에서 직접 입력). 개인 결제·발급 불필요.

타임존 (스케줄이 한국 시각으로 돌게)

  • n8n Cloud → Manage → Timezone = Asia/Seoul (UTC+9) 로 설정됨(미설정 시 GMT로 돌아 시각이 어긋나요).

데모 시트 탭 확인 — 강사가 올려둔 구글시트에서 아래 탭이 다 보이는지 ☑

  • 일일매출 (Lab2·Lab3용)
  • 주간매출 (Lab4용)
  • CS문의 (Lab4-AI용)
  • 요약시트 (빈 탭 — 집계 결과를 여기에 씀)
  • 분류결과 (빈 탭 — AI 분류 결과를 여기에 씀)

채워 넣은 내 데모 구글시트 ID(또는 파일명) 메모: ____________________

주의: UI 클릭 경로·노드 파라미터·typeVersion은 n8n 버전마다 달라질 수 있어요. 강의 전 본인 n8n Cloud에서 dry-run 1회로 확인한 값을 기준으로 채우세요.

Lab1. 편성표 → 담당자에게 자동 메일

이번 랩에서 만드는 것: 매일 아침 구글시트 편성표를 읽어, 각 방송 담당자에게 메일을 자동 발송하는 3노드 워크플로. 완성 모습(예상 결과): 노드 3개가 전부 녹색 체크 + 받은편지함에 "오늘 편성표 …" 메일 1통(본문에 시간·방송명·담당).

단계 체크리스트

[워크드] 강사 따라하기

  • 새 워크플로 생성 → 캔버스에 Schedule Trigger 추가
  • Schedule Trigger 설정: Interval = Days, 시각 = 09:00 (타임존 Asia/Seoul)
  • Google Sheets 노드 추가 → Operation = Get Row(s)(읽기) → 데모 시트 편성표 선택
  • 자가확인: Sheets 노드 실행 시 편성표 행들이 테이블로 보임 → 여기까지 됐으면 ✓

[페이드] 빈칸 채우기 — 아래를 직접 채우면서 Gmail 노드 설정

  • Gmail 노드 추가 → Operation = Send
항목 내가 채울 값(빈칸)
To (받는 사람) ____ ← 담당자 메일 필드를 표현식으로. 힌트: {{ $json.______ }}
Subject (제목) 오늘 편성표 - ____ ← 방송명을 표현식으로
본문(text) ____ ← 시간·방송명·담당을 표현식으로 조합

표현식 빈칸 워밍업(직접 적어보기):

  • 방송명 꺼내기 → {{ $json.______ }}
  • 담당자 메일 꺼내기 → {{ $json.______ }}
  • 한글/공백 들어간 필드가 점표기로 안 잡히면 → {{ $json[\"______\"] }} 대괄호 표기

[독립] 스스로

  • 세 노드를 Schedule → Sheets → Gmail 순서로 연결
  • 수동 실행(Execute Workflow)
  • 받은편지함에서 편성표 메일 1통 확인
  • 성공하면 워크플로를 Active(자동 실행) 로 토글

자가 확인 (녹색 체크)

  • 노드 3개 전부 녹색 ✓
  • 받은 메일 본문에 시간·방송명이 글자 그대로({{ }})가 아니라 실제 값으로 들어감 ✓
  • 여기까지 됐으면 Lab1 통과 ✓

흔한 실수 3개 (빠르게)

  1. Gmail 노드 빨강 "credential not found" → 구글 인증 미연결. Sign in with Google(Managed OAuth2) 또는 공용 데모 시트/수신함으로.
  2. 메일 본문에 {{ $json.방송명 }} 글자 그대로 나옴 → 표현식 토글 꺼짐 또는 필드명 오타. {{ }} 와 실제 키 이름 확인.
  3. 시트가 비어 보임 → 탭/범위를 잘못 선택. Sheet 드롭다운 재선택.

막히면: 강사 호출 또는 런북 참고. (자세한 절차는 30-exercises.md Lab1.)

Lab2. 조건분기 — 목표 매출 미달 방송만 골라내기

이번 랩에서 만드는 것: 일일매출을 읽어 매출 < 목표매출 인 방송만 골라 요약시트에 기록하는 워크플로. 완성 모습(예상 결과): IF 노드의 true 가지에 목표 미달 방송만 흐르고, 그 행들이 요약시트에 추가됨.

단계 체크리스트

[워크드] 강사 따라하기

  • Google Sheets Get Row(s) 로 일일매출 읽기
  • IF 노드 추가
  • IF 조건을 아래 빈칸으로 직접 구성 ↓

IF 조건 빈칸 채우기 (한 칸씩 적어보기)

IF 조건 부품 내가 채울 값
왼쪽 값(left) {{ $json.______ }} ← 비교할 매출 필드
비교 연산자 ____ ← "~보다 작다"는 영어로? (힌트: is s____ than / Number 타입)
오른쪽 값(right) {{ $json.______ }} ← 기준이 될 목표 필드
  • 자가확인: IF 실행 후 true / false 두 출력 분기가 생김 → 여기까지 됐으면 ✓

[페이드] 빈칸 채우기

  • IF의 true 경로에 Google Sheets 노드 추가
    • Operation = ____ (힌트: 행을 새로 추가하는 동작)
    • 대상 시트 = ____ (힌트: 빈 탭 이름)

[독립] 스스로 — IF vs Filter 비교

  • (택1) 같은 결과를 Filter 노드로도 만들어 본다.
  • IF와 Filter의 차이를 한 줄로 적기:

    IF = __________________________ Filter = __________________________ (힌트: 한쪽은 두 갈래로 갈라지고, 한쪽은 통과한 것만 남겨요.)

자가 확인 (녹색 체크)

  • IF가 숫자 타입으로 비교됨(문자열 아님) ✓
  • true 가지에 목표 미달 방송만 흐름 ✓
  • 요약시트에 미달 방송이 기록됨 ✓

흔한 실수 3개 (빠르게)

  1. 매출이 문자열("12,000,000")이라 비교가 항상 실패 → 콤마 제거 후 Number 변환(Edit Fields) 뒤 비교. 데모 일일매출_콤마.csv로 이 증상 직접 확인.
  2. IF 값 타입 불일치(Number vs String) → 조건의 데이터 타입을 Number로.
  3. true/false 가지를 거꾸로 연결 → 가지 라벨 확인.

막히면: 강사 호출 또는 런북 참고. (자세한 절차는 30-exercises.md Lab2.)

Lab3. 다중출력 — 상품군별 합산 → 요약시트 + 메일 2곳

이번 랩에서 만드는 것: 일일매출을 읽어 상품군별로 매출을 합산하고, 그 한 결과를 요약시트(쓰기)와 메일(발송) 두 곳으로 보내는 워크플로. 완성 모습(예상 결과): 상품군별 합계 1세트가 요약시트에 기록되고, 같은 요약이 메일로도 발송됨(목적지 2곳).

단계 체크리스트

[워크드] 강사 따라하기

  • Google Sheets Get Row(s) 로 일일매출 읽기
  • Summarize(집계) 노드 추가 → 아래 빈칸으로 집계 구성 ↓

집계 빈칸 채우기

Summarize 부품 내가 채울 값
합계 낼 필드(aggregation = sum) ____ (힌트: 숫자 매출 필드명)
묶는 기준(split by) ____ (힌트: 상품군)
  • 자가확인: 출력이 상품군별 합계 1줄씩 으로 나옴(예: 주방 합계 …, 패션 합계 …) → 여기까지 됐으면 ✓

[페이드] 빈칸 채우기

  • Google Sheets Append 로 요약시트에 집계 결과 쓰기
    • 매핑할 필드: {{ $json.______ }}(상품군) / {{ $json.______ }}(합계)

[독립] 스스로 — 하나의 결과를 두 곳으로

  • 집계 노드의 출력을 두 갈래로 분기: ① 요약시트 Append(이미) + ② Gmail Send(요약 메일)
  • Gmail 본문에 상품군별 합계를 매핑
  • (확장) 수신 대상에 팀 메일링리스트 추가

자가 확인 (녹색 체크)

  • 메일이 행마다 여러 통이 아니라 요약 1통으로 감 ✓
  • 요약시트 값과 메일 내용이 일치 ✓
  • 목적지가 2곳 이상 ✓

흔한 실수 3개 (빠르게)

  1. 집계 전에 발송 → 행마다 메일이 여러 통. 먼저 Summarize로 하나의 요약 아이템을 만든 뒤 발송.
  2. 요약시트에 덮어쓰기 vs 추가 혼동 → Append(추가) / Update(갱신) 구분.
  3. 매핑 필드명이 집계 노드 출력 키와 불일치 → 출력 Schema에서 실제 키 이름 확인.

막히면: 강사 호출 또는 런북 참고. (자세한 절차는 30-exercises.md Lab3.)

Lab4. 주간 성과 리포트 (게이트 분할 · 전원 완주)

Lab4는 1일차 부품을 조립하는 중심 과제예요. 게이트①(집계까지)과 게이트②(발송·에러·AI까지) 두 구간으로 나눠요. 막히면 import 파일을 불러와 다음 구간부터 합류하면 돼요 — 혼자만 뒤처지지 않게 설계돼 있어요.

게이트① — 스케줄 → 주간매출 읽기 → 집계 → 요약시트

이번 구간에서 만드는 것: 매주 월요일 08:00에 주간매출을 읽어 상품군별로 집계해 요약시트에 기록. 완성 모습: 4노드 녹색 + 요약시트에 주간 상품군별 합계 기록.

[독립] 스스로 (Lab1~3 부품 재사용)

  • Schedule Trigger → 매주 월요일 08:00(Asia/Seoul)
    • 빈칸 적기: 반복 단위 = ____(힌트: weeks), 요일 = ____(힌트: 월요일), 시각 = ____
  • Google Sheets Get Row(s) → 주간매출 읽기
  • Summarize → 상품군별 매출 합계(Lab3 재사용)
  • Google Sheets Append → 요약시트에 집계 쓰기

🚦 게이트① 자가 판정 (70분 지점)

  • 요약시트에 집계값이 쓰였고 워크플로가 녹색 실행 → 통과 ✓
  • 미통과 → 강사 검수 후 import 파일 ① (lab4-checkpoint1-집계까지.json) 을 "Import from File"로 불러와 게이트②부터 합류. (시트 ID·Credential은 본인 것으로 교체)

흔한 실수 3개: ① 날짜 필터 없이 전체 읽어 이번 주 아닌 데이터 집계 → 날짜 조건 추가. ② 집계 결과가 행마다 흩어짐 → 하나의 요약 아이템으로. ③ 타임존 미설정으로 실행 시각 어긋남 → Manage→Timezone Asia/Seoul 확인.

게이트② — 포맷팅 → 다중발송 → 에러 핸들링 → AI 분류/요약

이번 구간에서 만드는 것: 게이트① 결과를 사람이 읽을 텍스트로 포맷팅 → 팀장+메일링리스트 다중발송 → 에러 핸들링 추가 → CS 문의를 AI로 분류·요약해 분류결과에 연동. 완성 모습: 다중발송 + 에러핸들링 + AI 노드 전부 녹색 + CS 분류/요약이 시트/메일에 기록.

[페이드] 포맷팅·다중발송·에러 핸들링

  • Edit Fields(Set) 로 요약 본문 구성
    • 빈칸: {{ $json.______ }} 합계 {{ $json.______ }} (상품군 / 합계)
  • Gmail Send → 팀장 주소
  • Gmail Send → 팀 메일링리스트 (포맷팅 결과를 두 갈래로 분기)
  • Error Trigger 노드 추가 (본 흐름과 연결 없는 독립 노드 — 실패가 나면 이 트리거가 잡아요)
  • (검증) 의도적 오류(잘못된 시트 ID 등)를 넣고 Executions(실행 로그) 에서 원인 확인

🚦 게이트② 중간 자가 판정

  • 다중발송 + 에러핸들링 녹색 ✓
  • 미통과 → import 파일 ② (lab4-checkpoint2-발송까지.json) 불러와 AI 노드만 마무리.

[독립] AI 분류/요약 핸즈온 — 직접 손으로 (회사 API 키)

여기가 수강생 직접 핸즈온 구간이에요. 워크플로의 AI 노드는 회사가 제공한 Anthropic API 키로 연결합니다 — 개인 Claude 구독(claude.ai)으로는 동작하지 않습니다.

  • Google Sheets Get Row(s) 로 CS문의 읽기
  • Basic LLM Chain(루트) 노드 추가
  • Anthropic Chat Model(서브) 노드 추가 → Anthropic Chat Model → Basic LLM Chain 으로 연결
  • Anthropic 노드 Credential = New → Anthropic API → 회사 제공 키 붙여넣기
    • 채워 적기: 인증 종류 = ____(힌트: Anthropic API 키, claude.ai 구독 아님)
    • 모델명 = ____ (강의 전 dry-run에서 선택한 값으로)
  • 프롬프트는 assets/prompts/cs-분류요약.md 본문을 그대로 사용
    • 분류 라벨은 정확히 [ 배송 / 환불 / 상품문의 / 기타 ] 중 하나
    • 출력은 JSON 형식 강제: {\"분류\":\"...\",\"요약\":\"...\"}
    • 문의 입력 표현식 빈칸: {{ $json.______ }} (힌트: 문의내용 필드)
