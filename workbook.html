Lab 1. self-host 설치 — Docker 없이 · Claude Code 주도

이번 랩에서 만드는 것: 내 노트북에 Docker 없이 n8n을 직접 띄운다. 명령을 외우지 않고 Claude Code에게 시켜서 설치하고, 에러가 나면 함께 푼다. 완성 모습(예상 결과): http://localhost:5678 에디터 접속 + Setup Wizard로 Owner 계정 생성 + 빈 워크플로에 Manual Trigger 1개 실행이 녹색.

💡 Claude Code가 설치를 "대신 다 해줘요." 명령어를 외우거나 직접 칠 필요가 없어요. "내 컴퓨터에 n8n 설치해줘" 한마디면 Claude Code가 → ① node -v로 Node 버전 확인(없으면 nvm 설치 안내) → ② GENERIC_TIMEZONE=Asia/Seoul npx n8n 실행 → ③ 다운로드·기동 대기 → ④ localhost:5678 접속 주소 안내 → ⑤ 에러(포트 충돌·계정 비번 분실 등)까지 함께 해결 — 설치 전 과정을 대신 진행합니다. 여러분이 직접 할 건 딱 셋이에요: ① 브라우저 열기 ② 계정 이메일·비번 입력 ③ (Node 설치 같은) 시스템 변경 승인. 나머지는 Claude Code가 합니다.

단계 체크리스트

[워크드] 강사 따라하기 — Claude Code에게 그대로 부탁

  • Claude Code에 이렇게 입력:

  • Claude Code가 node -v 로 Node 확인 → 없거나 범위 밖이면 nvm 설치/전환 안내(nvm install 20). 시스템 변경(Node 설치)은 내가 승인.
  • Claude Code가 실행하는 핵심 명령을 눈으로 확인(직접 받아 적기):

    타임존 붙여 실행하는 명령 → GENERIC_TIMEZONE=______ npx n8n (힌트: Asia/Seoul)

  • 자가확인: 터미널에 n8n이 떴다는 메시지 + 브라우저 주소가 안내됨 → 여기까지 됐으면 ✓

Lab 2. 첫 워크플로 + n8n-MCP — 편성표 → 담당자 메일

이번 랩에서 만드는 것: 스케줄 → 구글시트 편성표 읽기 → 담당자에게 메일. n8n-MCP를 Claude Code에 연결해 정확한 노드 정보로 JSON 초안을 만든 뒤, 에디터에서 노드별로 import·실행(혼합 방식). 완성 모습(예상 결과): 3노드가 전부 녹색 + 받은편지함에 "오늘 편성표 …" 메일 1통.

단계 체크리스트

[워크드] 강사 따라하기 — n8n-MCP 연결 + 빌드

  • n8n-MCP 연결(AI-native 두뇌) — 터미널에서 한 번만 등록:
    claude mcp add n8n-mcp -e MCP_MODE=stdio -e LOG_LEVEL=error -e DISABLE_CONSOLE_OUTPUT=true -- npx n8n-mcp

    윈도우 PowerShell은 각 -e ... 를 따옴표로 감싸기('-e MCP_MODE=stdio' …). 등록 후 Claude Code 재시작 → claude mcp list 에서 n8n-mcp ✔ Connected 확인. 오늘 쓰는 건 커뮤니티 n8n-mcp. ★API 키 없이도 노드 조회·검증 툴이 작동(Lab2엔 충분). 워크플로 생성/실행까지 하려면 N8N_API_URL·N8N_API_KEY 추가.

  • n8n-MCP에 정확 노드 정보 물어보기:

    "스케줄 트리거 노드의 정확한 파라미터 알려줘" / "Google Sheets 읽기 노드 파라미터 알려줘"

    • 자가확인: n8n-MCP가 준 노드명을 에디터에서 그대로 썼더니 동작했는가? ____
  • Claude Code 빌드 미션: "스케줄(매일 09:00 Asia/Seoul) → 구글시트 편성표 읽기 → 담당자 메일, 이 3노드 워크플로 JSON 초안 만들어줘."

Lab 4. 조건분기·데이터처리·다중출력 — 일일매출 집계

이번 랩에서 만드는 것: 일일매출 읽기 → IF/Filter(목표 미달 추출) → 상품군별 집계(group/sum) → 요약시트 → 다중 발송. 표현식은 Claude Code 초안 + 에디터 실행으로 검증. 완성 모습: 상품군별 합계가 요약시트에 기록 + 담당자·팀장 다중발송 녹색.

단계 체크리스트

[페이드] 표현식 미니청크 (직접 적기)

  • 상품군 꺼내기 → {{ $json.____ }}
  • 한글/공백 매출 필드 → {{ $json["____"] }} (대괄호 표기)

[페이드] 조건분기 — IF 조건 빈칸 채우기

  • Google Sheets Get Row(s) 로 일일매출 읽기.
  • IF 노드 추가 → 아래 빈칸으로 조건 구성 ↓
IF 조건 부품 내가 채울 값
왼쪽 값(left) {{ $json.______ }} ← 비교할 매출 필드
비교 연산자 ____ ← "~보다 작다"는 영어로? (힌트: is s____ than · Number 타입)
오른쪽 값(right) {{ $json.______ }} ← 기준이 될 목표 필드

IF vs Filter 한 줄로 적기:

  • IF = __________________________ (힌트: 두 갈래로 갈라짐 true/false)
  • Filter = __________________________ (힌트: 통과한 것만 남김)

[페이드] 집계 — Summarize 빈칸 채우기

  • Summarize 노드 추가.
Summarize 부품 내가 채울 값
합계 낼 필드(aggregation = sum) ____ (힌트: 숫자 매출 필드명)
묶는 기준(split by) ____ (힌트: 상품군)
출력 합계 키 ____ (힌트: 강의 정본 출력키 sum_매출)
  • 자가확인: 출력이 상품군별 합계 1줄씩 으로 나옴 → 여기까지 됐으면 ✓

[독립] 스스로 — 요약시트 + 다중발송

  • Google Sheets Append 로 요약시트에 집계 쓰기
    • 매핑: {{ $json.______ }}(상품군) / {{ $json.______ }}(합계)
  • 같은 결과를 담당자 + 팀장 두 곳으로 다중 발송(Gmail Send 두 갈래).
  • Claude Code 적용: Lab3 PRD를 붙여 "이 가공·집계 노드 표현식 만들어줘" → 에디터 실행으로 검증.

자가 확인 (체크포인트 ☑)

  • IF가 숫자 타입으로 비교됨(문자열 아님) ✓
  • 상품군별 합계가 요약시트에 기록 ✓
  • 다중발송(2곳 이상) 녹색 ✓

막히면 — 흔한 실수 3개

  1. 매출이 문자열("12,000,000")이라 비교 항상 실패 → 콤마 제거 후 Number 변환(Edit Fields) 뒤 비교. 데모 일일매출_콤마.csv로 증상 확인.
  2. 집계 전에 발송 → 행마다 메일 여러 통. 먼저 Summarize로 하나의 요약 만든 뒤 발송.
  3. 표현식 대소문자·$json. 접두사를 AI가 틀리게 줌 → 에디터 실행으로 잡기.
