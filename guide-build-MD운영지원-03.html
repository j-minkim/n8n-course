03. 📞 콜센터 폭주 조기경보

콜 대기·포기율이 임계를 넘으면 Claude 조치 제안과 함께 운영팀에 긴급 경보를 보냅니다.

받는 사람: 운영팀 · 분류: MD·운영 지원 · 시트: 콜현황 탭 헤더: 진행중방송 · 현재대기 · 콜포기율 · 상담원가동 (콜시스템 실시간 export)

처음 만드는 필드 종류(노드 추가·연결·표현식 토글·크리덴셜)는 공통 조작법을 먼저 보세요.

노드 순서 (총 6개): 피크시간 3분마다 → 콜 현황 읽기 → 폭주 임계 판정 → 폭주일 때만 → Claude 조치 제안 → 운영팀 긴급 경보

Step 1 — 피크시간 3분마다 추가

  • 검색어: Schedule Trigger
  • 속성 설정: Trigger Interval → Minutes 선택 → Minutes Between Triggers = 3
  • 연결: 이 노드가 시작점입니다(입력 연결 없음).

Step 2 — 콜 현황 읽기 추가

  • 검색어: Google Sheets
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Google 계정 선택
    • Resource = Sheet Within Document (기본값)
    • Operation = Get Row(s) (기본값, 바꿀 필요 없음)
    • Document → By URL 또는 By ID → 본인 구글시트 ID 붙여넣기 (원본엔 YOUR_GOOGLE_SHEET_ID 자리)
    • Sheet → 콜현황 탭 선택 (드롭다운에 없으면 gid=0으로 첫 탭 지정)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 3 — 폭주 임계 판정 추가

  • 검색어: Code
  • 속성 설정: Mode = Run Once for All Items (기본값, 바꾸지 않음) → JavaScript 편집창에 아래 코드를 그대로 붙여넣기:
const r=$json;
const num=v=>Number(String(v||0).replace(/[,%\s]/g,''))||0;
const 대기=num(r['현재대기']);
const 포기율=num(r['콜포기율']);
const 폭주=(대기>=30)||(포기율>=15);
return [{json:{진행방송:r['진행중방송']||'-',현재대기:대기,콜포기율:포기율,상담원가동:r['상담원가동']||'-',폭주:String(폭주)}}];
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 눌러서 출력 JSON에 기대한 필드(위 코드의 return에 있는 키들)가 정확히 나오는지 확인하세요. 여기서 필드명 오타가 나면 다음 노드부터 전부 빈 값이 됩니다.

Step 4 — 폭주일 때만 추가

  • 검색어: If
  • 속성 설정: Add Condition 클릭 →
    • 왼쪽 값(Value): 표현식 토글(=) 켜고 → {{ $json['폭주'] }}
    • 연산자(Operator): 문자열 › is equal to (같다)
    • 오른쪽 값(Value): true
  • 동작 방식: If는 조건에 따라 출력이 True/False 두 갈래로 갈립니다. 이 템플릿에서는 True 쪽 출력만 다음 노드에 연결하세요(False는 그냥 끝).
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 5 — Claude 조치 제안 추가

  • 검색어: HTTP Request
  • 속성 설정:
    • Method = POST
    • URL = https://api.anthropic.com/v1/messages
    • Authentication = Generic Credential Type → Generic Auth Type = Header Auth → Credential = 공통 조작법에서 만든 x-api-key 크리덴셜 선택
    • Send Headers = On → Add Header 2번:
      • anthropic-version = 2023-06-01
      • content-type = application/json
    • Send Body = On → Body Content Type = JSON → Specify Body = Using JSON → 필드의 표현식 토글(=) 켜고 아래를 그대로 붙여넣기:
{{ JSON.stringify({ model: 'claude-sonnet-5', max_tokens: 350, messages: [{ role: 'user', content: '홈쇼핑 콜센터가 폭주 임계를 넘었다. 운영자가 즉시 취할 조치 2~3가지를 한국어 한 줄씩 제안해줘(예: 상담원 증원 호출, ARS/챗봇 유도, 방송 자막으로 모바일주문 안내).\n진행 방송: ' + $json['진행방송'] + ' / 현재 대기 ' + $json['현재대기'] + '명 / 콜포기율 ' + $json['콜포기율'] + '%' }] }) }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 content[0].text에 Claude의 응답 문장이 들어있는지 확인. invalid x-api-key 에러면 크리덴셜 값을 다시 확인하세요.

Step 6 — 운영팀 긴급 경보 추가

  • 검색어: Gmail
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Gmail 계정 선택
    • Operation = Send (기본값)
    • To: 표현식 토글 끄고 → YOUR_OPS@example.com (본인 이메일로 교체해서 테스트)
    • Subject: 표현식 토글(=) 켜고 → [콜폭주] 대기 {{ $('폭주 임계 판정').item.json['현재대기'] }}명 · 포기율 {{ $('폭주 임계 판정').item.json['콜포기율'] }}%
    • Email Type = Text
    • Message: 표현식 토글(=) 켜고 →
⚠️ 콜센터 폭주
- 진행 방송: {{ $('폭주 임계 판정').item.json['진행방송'] }}
- 현재 대기: {{ $('폭주 임계 판정').item.json['현재대기'] }}명 / 콜포기율 {{ $('폭주 임계 판정').item.json['콜포기율'] }}%
- 상담원 가동: {{ $('폭주 임계 판정').item.json['상담원가동'] }}

[조치]
{{ $json.content[0].text }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

✅ 완성 후 테스트: 트리거 노드에서 Test step(또는 Execute Workflow) → 마지막 노드까지 전부 초록불이 뜨는지 확인. 안 뜨면 그 노드를 더블클릭해 에러 메시지를 읽고, 표현식 토글(=)이 켜져 있는지부터 확인하세요.
