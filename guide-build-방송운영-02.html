02. 방송 결과 리포트 자동 초안

방송 종료 후 매출·주문·콜·반품 지표를 모아 Claude가 '잘된 점/아쉬운 점/개선안' 리포트 초안을 써서 MD에게 보내고 아카이브합니다.

받는 사람: MD · 분류: 방송 운영 · 시트: 방송결과 탭 헤더: 방송명 · 목표매출 · 매출 · 주문건수 · 콜인입 · 콜포기율 · 반품건수

처음 만드는 필드 종류(노드 추가·연결·표현식 토글·크리덴셜)는 공통 조작법을 먼저 보세요.

노드 순서 (총 6개): 방송 종료 후 23:30 → 방송결과 지표 읽기 → 지표 정리 → Claude 리포트 작성 → MD 리포트 초안 → 리포트 아카이브

Step 1 — 방송 종료 후 23:30 추가

  • 검색어: Schedule Trigger
  • 속성 설정: Trigger Interval → Days 선택 → Hour = 23, Minute = 30 (n8n 인스턴스 타임존이 이미 Asia/Seoul이면 이게 곧 한국시간입니다 — 1일차 설치 때 GENERIC_TIMEZONE=Asia/Seoul로 띄운 그 설정)
  • 연결: 이 노드가 시작점입니다(입력 연결 없음).

Step 2 — 방송결과 지표 읽기 추가

  • 검색어: Google Sheets
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Google 계정 선택
    • Resource = Sheet Within Document (기본값)
    • Operation = Get Row(s) (기본값, 바꿀 필요 없음)
    • Document → By URL 또는 By ID → 본인 구글시트 ID 붙여넣기 (원본엔 YOUR_GOOGLE_SHEET_ID 자리)
    • Sheet → 방송결과 탭 선택 (드롭다운에 없으면 gid=0으로 첫 탭 지정)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 3 — 지표 정리 추가

  • 검색어: Code
  • 속성 설정: Mode = Run Once for All Items (기본값, 바꾸지 않음) → JavaScript 편집창에 아래 코드를 그대로 붙여넣기:
const r=$json;
const num=v=>Number(String(v||0).replace(/[,\s]/g,''))||0;
const 목표=num(r['목표매출']),매출=num(r['매출']);
const 달성률=목표>0?Math.round(매출/목표*100):0;
const 주문=num(r['주문건수']),반품=num(r['반품건수']);
const 반품률=주문>0?Math.round(반품/주문*100):0;
const metrics=`방송: ${r['방송명']||'-'}\n목표매출 ${목표.toLocaleString()} / 매출 ${매출.toLocaleString()} (달성률 ${달성률}%)\n주문 ${주문}건 / 콜인입 ${r['콜인입']||'-'} / 콜포기율 ${r['콜포기율']||'-'} / 반품 ${반품}건(반품률 ${반품률}%)`;
return [{json:{방송명:r['방송명'],달성률,metrics}}];
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 눌러서 출력 JSON에 기대한 필드(위 코드의 return에 있는 키들)가 정확히 나오는지 확인하세요. 여기서 필드명 오타가 나면 다음 노드부터 전부 빈 값이 됩니다.

Step 4 — Claude 리포트 작성 추가

  • 검색어: HTTP Request
  • 속성 설정:
    • Method = POST
    • URL = https://api.anthropic.com/v1/messages
    • Authentication = Generic Credential Type → Generic Auth Type = Header Auth → Credential = 공통 조작법에서 만든 x-api-key 크리덴셜 선택
    • Send Headers = On → Add Header 2번:
      • anthropic-version = 2023-06-01
      • content-type = application/json
    • Send Body = On → Body Content Type = JSON → Specify Body = Using JSON → 필드의 표현식 토글(=) 켜고 아래를 그대로 붙여넣기:
{{ JSON.stringify({ model: 'claude-sonnet-5', max_tokens: 800, messages: [{ role: 'user', content: '다음은 오늘 홈쇼핑 방송 결과 지표다. MD가 팀에 공유할 방송 결과 리포트 초안을 아래 4개 소제목으로 한국어로 작성해줘: [요약] [잘된 점] [아쉬운 점] [다음 방송 개선안]. 사실 기반으로 간결하게.\n' + $json['metrics'] }] }) }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 content[0].text에 Claude의 응답 문장이 들어있는지 확인. invalid x-api-key 에러면 크리덴셜 값을 다시 확인하세요.

Step 5 — MD 리포트 초안 추가

  • 검색어: Gmail
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Gmail 계정 선택
    • Operation = Send (기본값)
    • To: 표현식 토글 끄고 → YOUR_MD@example.com (본인 이메일로 교체해서 테스트)
    • Subject: 표현식 토글(=) 켜고 → [방송리포트] {{ $('지표 정리').item.json['방송명'] }} (달성률 {{ $('지표 정리').item.json['달성률'] }}%)
    • Email Type = Text
    • Message: 표현식 토글(=) 켜고 →
{{ $('지표 정리').item.json['metrics'] }}

─────────────
{{ $json.content[0].text }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 6 — 리포트 아카이브 추가

  • 검색어: Google Sheets
  • 속성 설정:
    • Credential: 공통 조작법에서 만든 Google 계정 선택
    • Resource = Sheet Within Document (기본값)
    • Operation = Append Row
    • Document → By URL 또는 By ID → 본인 구글시트 ID 붙여넣기 (원본엔 YOUR_GOOGLE_SHEET_ID 자리)
    • Sheet → 방송리포트로그 탭 선택 (드롭다운에 없으면 새로 만들거나 gid=0으로 첫 탭 지정)
    • Mapping Column Mode = Map Automatically Below (들어오는 데이터의 필드명을 시트 헤더와 자동 매칭 — 시트 헤더를 입력 필드명과 똑같이 만들어두세요)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

⚠️ 가지 나뉘는 지점(fan-out):

  • Claude 리포트 작성의 출력(●)에서 드래그를 두 번 해서 MD 리포트 초안 · 리포트 아카이브 둘 다에 연결하세요(같은 출력에서 두 갈래로 나갑니다 — 다중출력).

✅ 완성 후 테스트: 트리거 노드에서 Test step(또는 Execute Workflow) → 마지막 노드까지 전부 초록불이 뜨는지 확인. 안 뜨면 그 노드를 더블클릭해 에러 메시지를 읽고, 표현식 토글(=)이 켜져 있는지부터 확인하세요.
