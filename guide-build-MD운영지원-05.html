05. 💬 CS 문의 AI 분류·요약

고객 문의(웹훅 수신)를 Claude가 카테고리 분류·요약해 날짜별 CSV로 기록합니다.

받는 사람: CS팀 · 분류: MD·운영 지원 · 데이터 파일: 웹훅 입력(JSON 필드 message) → 결과는 CS로그_날짜시각.csv로 자동 저장 — ~/.n8n-files에 넣기

  • ★웹훅에 Header Auth 인증이 걸려 있어요(공개 URL 보호) — 호출 측도 같은 헤더를 보내야 합니다. 사내 테스트만이면 웹훅 노드 Authentication을 None으로 바꿔도 됩니다.

처음 만드는 필드 종류(노드 추가·연결·표현식 토글·크리덴셜)는 공통 조작법을 먼저 보세요.

🤖 경로 A — Claude Code에게 시키기 (메타프롬프트)

이 강의의 방식대로, 아래 프롬프트를 Claude Code에 그대로 붙여넣으면 이 워크플로 JSON을 만들어줍니다(n8n-MCP 연결 시 더 정확). 받은 JSON을 ⋮ → Import from File로 불러온 뒤 노드별 Test step으로 검증하세요 — AI 초안은 가설, 진실은 에디터 실행 결과입니다.

n8n 워크플로 JSON을 만들어줘: "CS 문의 AI 분류·요약" 자동화야. (기록은 CSV 파일 기준)

[목표] 고객 문의가 웹훅으로 들어오면 Claude가 카테고리 분류·요약하고, 결과를 날짜별 CSV로 기록.

[노드 체인 — 5개, 순서대로]
1. Webhook — POST, Path `cs-inquiry`, Options→Response Data `firstEntryJson`.
   ★Authentication = Header Auth(공개 웹훅 보호) — 호출 측도 같은 헤더 전송(사내 테스트만이면 None 가능).
2. HTTP Request(POST) — Claude에게 "고객 문의를 카테고리(배송/교환/환불/상품문의/기타) 분류하고 2줄 요약" 요청.
   문의 본문은 웹훅 body의 `message` 필드에서. (max_tokens 300)
3. Code — 결과 정리(노드 이름 '결과 정리'): $('CS 문의 수신 (Webhook)')의 body.message + Claude 응답(content[0].text)을 {문의, 분석}으로.
4. Convert to File — CSV 변환 (노드 이름 'CS로그 CSV 변환')
5. Read/Write Files from Disk — 쓰기: YOUR_DATA_DIR/CS로그_{{ $now.format('yyyy-LL-dd_HHmm') }}.csv

★테스트: Active 켠 뒤 `curl -X POST .../webhook/cs-inquiry -H "Content-Type: application/json" -H "<인증헤더>" -d '{"message":"배송이 늦어요"}'`

[공통 규칙 — 그대로 지켜줘]
- n8n-MCP가 연결돼 있으면 각 노드의 정확한 파라미터를 조회해서 만들고, 없으면 표준 노드 구조로.
- 데이터는 CSV 파일 기준: 경로는 YOUR_DATA_DIR/… 플레이스홀더로.
  (self-host n8n은 ~/.n8n-files 안의 파일만 접근 가능 — 사용자가 절대경로로 교체할 것)
- Claude 호출은 HTTP Request 노드로: POST https://api.anthropic.com/v1/messages,
  인증은 Header Auth 크리덴셜(이름 x-api-key), 추가 헤더 anthropic-version: 2023-06-01,
  모델 claude-sonnet-5, 응답 본문은 content[0].text 로 파싱.
- 수신자 이메일은 YOUR_...@example.com 플레이스홀더로.
- connections의 타입은 전부 "main". IF 노드는 true 출력만 다음 노드로.
- 완성되면 워크플로 JSON을 파일로 저장해줘 — 내가 n8n에서 ⋮ → Import from File 로 불러올게.
- import 후엔 노드별 Test step으로 하나씩 검증할 거야(통째로 맞다고 가정하지 말 것).

🗂 이 프롬프트는 기본(파일 버전) 기준입니다. 팀 공유용 구글시트 버전(보조)이 필요하면 파일 버전 가이드 §4의 시트 변환 단락을 덧붙이세요.

🔧 경로 B — 손으로 직접 만들기 (스텝바이스텝)

노드가 왜 이 순서로 놓이는지 이해하려면 이 경로로. 아래 Step은 기본(파일 버전) 기준입니다 — 구글시트 버전(보조)은 파일 노드 2단 자리에 Google Sheets 노드 1개가 들어갑니다: 차이 보기

노드 순서 (총 5개): CS 문의 수신 (Webhook) → Claude 분류·요약 → 결과 정리 → CS로그 CSV 변환 → 시트에 기록

Step 1 — CS 문의 수신 (Webhook) 추가

  • 검색어: Webhook
  • 속성 설정:
    • HTTP Method = POST
    • Path = cs-inquiry
    • Options → Response Data = firstEntryJson
    • Authentication = Header Auth → 크리덴셜 생성(임의의 헤더 이름/값) — 호출하는 쪽도 같은 헤더를 보내야 합니다(사내 테스트만이면 None으로 둬도 됨)
  • 연결: 이 노드가 시작점입니다. 테스트는 에디터의 Test URL로 curl POST → Active 켠 뒤엔 /webhook/ 경로 사용.

Step 2 — Claude 분류·요약 추가

  • 검색어: HTTP Request
  • 속성 설정:
    • Method = POST
    • URL = https://api.anthropic.com/v1/messages
    • Authentication = Generic Credential Type → Generic Auth Type = Header Auth → Credential = 공통 조작법에서 만든 x-api-key 크리덴셜 선택
    • Send Headers = On → Add Header 2번:
      • anthropic-version = 2023-06-01
      • content-type = application/json
    • Send Body = On → Body Content Type = JSON → Specify Body = Using JSON → 필드의 표현식 토글(=) 켜고 아래를 그대로 붙여넣기:
{{ JSON.stringify({ model: 'claude-sonnet-5', max_tokens: 300, thinking: { type: 'disabled' }, messages: [{ role: 'user', content: '다음 고객 문의를 카테고리(배송/환불/상품/기타) 중 하나로 분류하고 한 줄 요약해줘. \'카테고리: X / 요약: Y\' 형식.\n문의: ' + ($json.body?.['message']||$json['문의']||'') }] }) }}
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step에서 content[0].text에 Claude의 응답 문장이 들어있는지 확인. invalid x-api-key 에러면 크리덴셜 값을 다시 확인하세요.

Step 3 — 결과 정리 추가

  • 검색어: Code
  • 속성 설정: Mode = Run Once for All Items (기본값, 바꾸지 않음) → JavaScript 편집창에 아래 코드를 그대로 붙여넣기:
return [{json:{문의:(($('CS 문의 수신 (Webhook)').item.json.body||{}).message)||'', 분석:$json.content[0].text}}];
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: Test step 눌러서 출력 JSON에 기대한 필드(위 코드의 return에 있는 키들)가 정확히 나오는지 확인하세요. 여기서 필드명 오타가 나면 다음 노드부터 전부 빈 값이 됩니다.

Step 4 — CS로그 CSV 변환 추가

  • 검색어: Convert to File
  • 속성 설정: Operation = Convert to CSV (엑셀로 저장하려면 Convert to XLSX)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 5 — 시트에 기록 추가

  • 검색어: Read/Write Files from Disk
  • 속성 설정:
    • Operation = Write File to Disk
    • File Path and Name: 표현식 토글(=) 켜고 → YOUR_DATA_DIR/CS로그_{{ $now.format('yyyy-LL-dd_HHmm') }}.csv
    • Input Binary Field = data (기본값)
    • YOUR_DATA_DIR는 본인 ~/.n8n-files 절대경로로 교체 (macOS /Users/계정/.n8n-files · 윈도우 C:\Users\계정\.n8n-files)
  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)
  • 테스트 포인트: 실행 후 폴더에 날짜가 붙은 파일이 생겼는지 확인. Access to the file is not allowed 에러면 경로가 ~/.n8n-files 밖입니다(에러 전문을 Claude Code에 붙여넣으면 해결).

✅ 완성 후 테스트: 트리거 노드에서 Test step(또는 Execute Workflow) → 마지막 노드까지 전부 초록불이 뜨는지 확인. 안 뜨면 그 노드를 더블클릭해 에러 메시지를 읽고, 표현식 토글(=)이 켜져 있는지부터 확인하세요.
