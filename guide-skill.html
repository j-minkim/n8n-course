자동화 PRD 경량 스킬 — /n8n-automation-prd

워크플로를 만들기 전에, "무엇을 자동화할지"를 5섹션 PRD로 한 번에 정리해 주는 Claude Code 전용 경량 스킬입니다. Day2 B1(Lab3)·B6~B7(Lab6)에서 사용해요.

무엇을 해 주나

  • 자동화할 업무를 한 줄로 주면 → 5섹션 PRD(① 트리거 ② 입력 ③ 처리 ④ 출력 ⑤ 예외·한도)를 한 턴에 만들어 줍니다. 추론 가능한 칸은 (추정)으로 미리 채우고, 비는 칸만 한꺼번에 물어봐요.
  • 이어서 PRD를 n8n 6레이어(트리거·수집·가공·AI 판단·액션/알림·에러)로 매핑해 줍니다.
  • 단계 게이트로 안전하게: ① 설계 확정 → ② JSON 초안 → ③ 실제 생성을 끊어서 진행합니다. 한 번의 "OK"로 실제 n8n 생성까지 가지 않아요(실습 기본은 import).

왜 경량인가 (vs brainstorming)

범용 superpowers:brainstorming은 질문을 하나씩 던지고 접근법을 비교하느라 토큰을 많이 씁니다. 이 스킬은 n8n 전용이라 보통 1턴에 끝나요. 정말 크고 복잡한 설계(여러 제품·복잡한 정책)일 때만 brainstorming으로 올리면 됩니다.

설치 (둘 중 하나)

A. 폴더 복사 (권장)

  1. ⬇ n8n-automation-prd-skill.zip 내려받기 후 압축을 풉니다.
  2. n8n-automation-prd/ 폴더를 통째로 아래 위치에 넣습니다.
    • macOS / Linux: ~/.claude/skills/
    • Windows: %USERPROFILE%\.claude\skills\
  3. Claude Code를 재시작합니다.

B. 이미 설치돼 있는지 확인

  • Claude Code에서 / 를 입력했을 때 n8n-automation-prd가 보이면 설치된 것입니다.

설치 후 폴더 구조: ~/.claude/skills/n8n-automation-prd/SKILL.md + references/n8n-node-map.md

사용법

Claude Code에서:

/n8n-automation-prd
"매주 반복하는 ___ 업무를 자동화하고 싶어."

또는 그냥 평소 말투로 — "○○를 자동화하고 싶어", "이 반복업무 n8n으로 만들 수 있어?" 라고만 해도 스킬이 자동으로 붙습니다.

우리 회사(홈앤쇼핑) 예시 3개 — 그대로 실습해도 됩니다

예시 한 줄 정의 배우는 노드
ⓐ 방송 실적 리포트 "방송 끝나면 실적을 담당 MD에게 자동 정리·발송" Schedule · 집계(Summarize) · 다중 출력
ⓑ 경쟁사 가격 모니터링 "경쟁사 가격을 매일 체크해 우리보다 싸지면 알림" HTTP 수집 · IF 분기 · ★robots·약관
ⓒ 고객 리뷰 VOC 분류 "고객 리뷰를 AI로 긍/부정 분류해 부정만 담당팀 알림" Anthropic 노드(2일차) · IF 분기

흐름 한눈에

  1. 주제 한 줄 제시 → 2. 스킬이 5섹션 PRD + 6레이어 매핑을 한 번에 → 3. 비는 칸만 채워 "이 설계 맞나요?" 확정 → 4. (원하면) "JSON 초안 만들어줘" → 5. n8n에서 ⋮ → Import from File.

자주 묻는 것

  • PRD를 파일로 남기고 싶어요 → "이 PRD를 .md로 저장해줘"라고 하면 됩니다.
  • AI 판단 노드(③ 처리)는 무엇으로 도나요? → 워크플로 안 Anthropic 노드는 **별도 Anthropic API 키(종량과금)**로 돕니다. 개인 Claude 구독으로는 안 됩니다. 각자 제한 키를 쓰거나 강사 화면 시연으로 확인하며 키·Credential을 공유하지 않습니다.
  • 노드를 한 번에 다 만들어도 되나요? → 아니요. 거대 JSON 통째 생성은 cascade 에러 위험 → 노드별로 만들고 즉시 검증하세요.
