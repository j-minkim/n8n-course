실무 템플릿 — 기본은 파일(CSV) 버전이에요

크리덴셜 0개로 바로 시작 · 구글시트 버전은 팀 공유가 필요할 때 보조로

실무 10종 템플릿은 완전히 같은 자동화 로직을 두 벌로 제공합니다. 기본은 파일(CSV) 버전 — 내 컴퓨터의 CSV를 읽어서 크리덴셜 없이 바로 돌아갑니다. 팀과 데이터를 공유·동시 수정해야 할 때만 구글시트 버전(보조) 으로 갈아타면 됩니다.

📥 다운로드: ★기본 — 파일 버전 zip (실무 10종) · 보조 — 구글시트 버전 zip (전체 20종, 기본 L1~L4 포함)

1. 왜 파일 버전이 기본인가

  • 크리덴셜 0개 — Google OAuth(redirect URI 등)에서 막힐 일이 없음. import하고 CSV만 넣으면 바로 실행
  • 사내 시스템 궁합 — 콜시스템·BI가 주는 CSV export 폴더를 그대로 물릴 수 있음
  • 보안 — 회사 정책상 구글 계정 연동이 어려운 환경에서도 동작

구글시트 버전(보조)으로 갈아타야 할 때:

상황 이유
팀원과 데이터를 공유·동시 수정 시트는 여러 명이 한 표를 같이 봄
폰·다른 PC에서 데이터를 고치고 싶다 시트는 어디서든 접근
아카이브를 한 표에 누적하고 싶다 파일 버전 아카이브는 날짜별 파일로 쌓임

💡 로직(Code·IF·Claude 프롬프트)은 두 버전이 동일합니다. 파일 버전(기본)으로 배우고 나중에 시트 버전으로 갈아타도 바뀌는 건 읽기/쓰기 노드뿐이에요.

2. 두 버전의 노드 차이 (매핑)

읽기:

[기본 · 파일 버전]   Read/Write Files from Disk (읽기: YOUR_DATA_DIR/방송예정상품.csv)
                      → Extract from File (CSV → 행 데이터)
                        ↕ 같은 자리를 서로 교체
[보조 · 시트 버전]   Google Sheets (Get Row(s), '방송예정상품' 탭)

쓰기(아카이브):

[기본 · 파일 버전]   Convert to File (행 데이터 → CSV)
                      → Read/Write Files from Disk (쓰기: 트렌드로그_2026-07-15_0930.csv)
                        ↕ 같은 자리를 서로 교체
[보조 · 시트 버전]   Google Sheets (Append Row, '트렌드로그' 탭)
  • 파일 버전의 아카이브는 실행할 때마다 날짜·시각이 붙은 새 CSV가 생깁니다(시트처럼 한 표에 누적되는 게 아니라 로그 폴더에 파일이 쌓이는 방식).
  • Code 노드가 참조하는 노드 이름($('방송예정 상품 읽기') 등)은 두 버전에서 동일하게 유지돼 있어서, 나머지 노드는 손댈 게 없습니다.

3. ★기본(파일) 버전 사용 전 꼭 알아야 할 한 가지 — ~/.n8n-files/

self-host n8n은 보안상 홈 폴더의 .n8n-files 폴더 안에 있는 파일만 읽고 쓸 수 있습니다. (아무 경로나 접근하면 Access to the file is not allowed 에러 — 실제 실행으로 확인했습니다.)

준비 3단계:

  1. 터미널에서 폴더 만들기: mkdir -p ~/.n8n-files
  2. CSV 데이터 파일을 그 안에 넣기 (헤더는 시트 버전과 동일 — zip 안 README에 표로 정리)
  3. import한 워크플로에서 YOUR_DATA_DIR를 본인 절대경로로 교체:
    • macOS: /Users/본인계정/.n8n-files
    • Windows: C:\Users\본인계정\.n8n-files

다른 폴더를 쓰려면 n8n 시작 시 N8N_RESTRICT_FILE_ACCESS_TO=/원하는/경로 환경변수를 추가하면 됩니다. ⚠️ 아카이브 파일명의 시각이 이상하면 n8n을 GENERIC_TIMEZONE=Asia/Seoul로 띄웠는지 확인하세요.

🧰 실전 막힘 카드 — "바탕화면에 뒀는데 에러가 나요" (실제 겪은 사례)

CSV를 바탕화면(Desktop) 에 두고 실행하면 이 에러가 납니다:

Access to the file is not allowed. Allowed paths: /Users/본인계정/.n8n-files

해결은 강의에서 배운 그대로 — 에러 전문을 복사해서 Claude Code에 붙여넣으세요. 그럼 두 가지 해법을 안내해줍니다:

  • (a) 파일을 옮기기: mv ~/Desktop/방송예정상품.csv ~/.n8n-files/ 후 워크플로 경로 수정 ← 보통 이거면 끝
  • (b) 허용 경로 넓히기: n8n을 N8N_RESTRICT_FILE_ACCESS_TO=$HOME/Desktop GENERIC_TIMEZONE=Asia/Seoul npx n8n으로 재시작 (바탕화면을 그대로 쓰고 싶을 때)

💡 이 에러는 사실 미리 겪어볼 가치가 있는 에러예요 — "빨간 에러 → 전문 복사 → Claude Code → 해법 검증"이라는 M6 디버깅 루프를 파일 하나로 연습하게 됩니다.

4. 메타프롬프트로 기본(파일) 버전 생성하기

빌드 가이드의 메타프롬프트는 시트 버전 기준으로 적혀 있어요. 기본(파일) 버전으로 만들려면 프롬프트 끝에 아래 한 단락만 덧붙이면 됩니다:

구글시트 노드 대신 파일 노드를 써줘:
- 읽기는 Read/Write Files from Disk(read, YOUR_DATA_DIR/파일명.csv) → Extract from File(csv) 2단으로,
- 쓰기(아카이브)는 Convert to File(csv) → Read/Write Files from Disk(write) 2단으로,
  쓰기 파일명은 "이름_{{ $now.format('yyyy-LL-dd_HHmm') }}.csv" 표현식으로.
- Code 노드가 $('노드명')으로 참조하는 이름은 Extract from File 노드가 그대로 물려받게 해줘.
- 참고: self-host n8n은 ~/.n8n-files 안의 파일만 접근 가능.

5. 검증 수준

  • 파일 버전 10종 전부 실제 n8n REST import 10/10 통과
  • 파일 노드 체인(읽기→CSV 파싱→Code→CSV 변환→쓰기)은 실데이터로 실제 실행 성공 (한글 파일명·한글 헤더 CSV 파싱, 날짜 파일명 생성까지 확인)
  • AI(★) 템플릿의 Claude 호출·메일 발송은 시트 버전과 동일 — 자격증명 연결 후 노드별 Test step으로 재검증하세요
