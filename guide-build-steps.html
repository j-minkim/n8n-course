홈앤쇼핑 실무 템플릿 10종 — 스텝바이스텝 빌드 가이드

"import 버튼 말고, 노드 하나씩 직접 쌓아보기"

이 문서는 실무 템플릿 카탈로그의 L5 실무 10종을 빈 캔버스에서부터 노드 하나씩 만드는 방법입니다. ⋮ → Import from File로 한 번에 불러오는 대신, 어떤 노드를 검색해서 추가하고, 어떤 속성을 채우고, 어떻게 연결하는지 전부 순서대로 보여줍니다. 완성된 JSON은 각 템플릿 zip(실습 파일 페이지에서 다운로드)을 열어 정답을 대조할 수 있어요.

💡 왜 손으로 만들어보나요? import는 "동작하는 걸 보는 것"이고, 직접 만들기는 "왜 이 노드가 이 자리에 있는지 이해하는 것"입니다. 본인 업무로 확장하려면 후자가 필요합니다.

0. 시작 전에 — 공통 조작법 (한 번만 읽으면 전체 적용)

0-1. 노드 추가하기

캔버스 오른쪽 위 ＋ 버튼(또는 캔버스 빈 곳 더블클릭) → 노드 패널이 열림 → 검색창에 노드 이름 입력(예: "Schedule Trigger") → 목록에서 클릭 → 캔버스에 노드가 놓입니다.

0-2. 노드 연결하기

한 노드의 **오른쪽 끝 원(●, 출력)**을 클릭한 채로 드래그해서 다음 노드의 **왼쪽 끝 원(●, 입력)**에 놓으면 선이 이어집니다. (Import한 파일을 보면 이미 이 선들이 그려져 있어요 — 직접 만들 땐 이 선을 우리가 긋는 것입니다.)

0-3. 노드 속성 설정 열기

노드를 더블클릭하면 오른쪽(또는 중앙)에 설정 패널이 열립니다. 여기서 각 필드를 채웁니다.

0-4. 표현식(Expression) 모드 — 가장 중요한 습관

필드 오른쪽의 = 토글 버튼을 켜야 {{ }} 안의 내용이 실제 값으로 치환됩니다. 토글이 꺼진 채로 {{ $json.상품명 }}을 입력하면 문자 그대로 저장돼 동작하지 않습니다. 이 가이드에서 "표현식 토글(=) 켜고"라고 나오면 반드시 켜세요.

0-5. $('노드명') 문법

표현식 안에서 바로 이전 노드가 아닌, 더 앞선 노드의 값을 가져올 때 씁니다. 예: $('발주 필요만').item.json['상품명'] = "발주 필요만" 노드가 넘긴 데이터에서 상품명 필드를 가져옴. 노드 이름은 정확히 일치해야 합니다(오타 나면 빨간 에러).

0-6. 자격증명 미리 만들어두기 (템플릿마다 반복 사용)

Google Sheets / Gmail — 노드 설정에서 Credential 드롭다운 → Create New Credential → Sign in with Google → 팝업에서 로그인·권한 승인. 한 번 만들면 이후 모든 템플릿에서 재사용.

Claude(HTTP Request) — Header Auth — HTTP Request 노드에서 Authentication을 Generic Credential Type → Header Auth로 설정 → Credential 드롭다운 → Create New Credential:

필드 값
Name x-api-key
Value 회사 Anthropic API 키

한 번 만들면 이후 모든 Claude(HTTP) 노드에서 이 크리덴셜을 재사용합니다.

0-7. 노드 테스트하기

설정 패널 아래 Test step(또는 캔버스에서 노드 우클릭 → Execute Node) 클릭 → 입력 데이터가 있으면 그걸 사용해 실행 → 오른쪽에 출력 결과가 표에/JSON으로 표시됩니다. 노드 하나 만들 때마다 바로 테스트하세요 — 마지막에 한 번에 돌리면 어디서 깨졌는지 찾기 어렵습니다.

0-8. 이 문서 읽는 법

템플릿마다 Step 1 → Step N이 실제 캔버스에 노드를 놓는 순서입니다. 각 Step은:

  • 어떤 노드를 검색해서 추가하나
  • 속성을 뭘로 채우나 (표현식은 그대로 복사해서 붙여넣기)
  • 어디에 연결하나

를 담고 있습니다. 완료 후 마지막 Step에서 전체 테스트 방법을 안내합니다.

🔧 경로 B — 손으로 직접 만들기

노드 순서 (총 7개): 매일 07:30 → 방송예정 상품 읽기 → 네이버쇼핑 최저가 조회 → 최저가 비교 → 가격 열위만 → Claude 대응 소구점 → MD 가격진단 메일

Step 1 — 매일 07:30 추가

  • 검색어: Schedule Trigger

  • 속성 설정: Trigger Interval → Days 선택 → Hour = 7, Minute = 30

    (n8n 인스턴스 타임존이 이미 Asia/Seoul이면 이게 곧 한국시간입니다 — 1일차 설치 때 GENERIC_TIMEZONE=Asia/Seoul로 띄운 그 설정)

  • 연결: 이 노드가 시작점입니다(입력 연결 없음).

Step 2 — 방송예정 상품 읽기 추가

  • 검색어: Google Sheets

  • 속성 설정:

    • Credential: 0-6에서 만든 Google 계정 선택

    • Resource = Sheet Within Document (기본값)

    • Operation = Get Row(s) (기본값, 바꿀 필요 없음)

    • Document → By URL 또는 By ID → 본인 구글시트 ID 붙여넣기 (원본엔 YOUR_GOOGLE_SHEET_ID 자리)

    • Sheet → 방송예정상품 탭 선택 (드롭다운에 없으면 gid=0으로 첫 탭 지정)

  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 3 — 네이버쇼핑 최저가 조회 추가

  • 검색어: HTTP Request

  • 속성 설정:

    • Method = GET

    • URL: 표현식 토글(=) 켜고 → https://openapi.naver.com/v1/search/shop.json?query={{ encodeURIComponent($json['상품명']) }}&display=20&sort=sim

    • Authentication = None (인증은 헤더로 직접 넣음 — 아래)

    • Send Headers = On → Add Header 2번:

      • X-Naver-Client-Id = YOUR_NAVER_CLIENT_ID

      • X-Naver-Client-Secret = YOUR_NAVER_CLIENT_SECRET

    • Send Body = Off (GET 요청이라 바디 없음, 값은 URL과 헤더로 전달)

  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

  • 테스트 포인트: Test step에서 items 배열에 상품 목록(title·lprice·mallName)이 들어있는지 확인. 401/403 에러면 네이버 Client ID/Secret을 다시 확인하세요.

Step 4 — 최저가 비교 추가

  • 검색어: Code

  • 속성 설정: Mode = Run Once for All Items (기본값, 바꾸지 않음) → JavaScript 편집창에 아래 코드를 그대로 붙여넣기:

const clean=s=>String(s||'').replace(/<[^>]+>/g,'');
let items=($json.items||[]).map(it=>({title:clean(it.title),price:Number(it.lprice)||0,mall:it.mallName})).filter(x=>x.price>0);
// ★액세서리·부품 이상치 제거: 가격 중앙값의 40% 미만은 버림(부품이 진짜 상품 최저가로 잡히는 것 방지)
const ps=items.map(x=>x.price).sort((a,b)=>a-b);
const median=ps.length?ps[Math.floor(ps.length/2)]:0;
items=items.filter(x=>x.price>=median*0.4);
items.sort((a,b)=>a.price-b.price);
const low=items[0]||{price:0,mall:'-',title:'-'};
const mine=Number(String($('방송예정 상품 읽기').item.json['우리방송가']||0).replace(/[,\s]/g,''))||0;
const gap=mine-low.price;
return [{json:{상품명:$('방송예정 상품 읽기').item.json['상품명'],우리방송가:mine,최저가:low.price,최저가몰:low.mall,가격차:gap,열위:String(gap>0)}}];

  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

  • 테스트 포인트: Test step 눌러서 출력 JSON에 기대한 필드(위 코드의 return에 있는 키들)가 정확히 나오는지 확인하세요. 여기서 필드명 오타가 나면 다음 노드부터 전부 빈 값이 됩니다.

Step 5 — 가격 열위만 추가

  • 검색어: If

  • 속성 설정: Add Condition 클릭 →

    • 왼쪽 값(Value): 표현식 토글(=) 켜고 → {{ $json['열위'] }}

    • 연산자(Operator): 문자열 › is equal to (같다)

    • 오른쪽 값(Value): true

  • 동작 방식: If는 조건에 따라 출력이 True/False 두 갈래로 갈립니다. 이 템플릿에서는 True 쪽 출력만 다음 노드에 연결하세요(False는 그냥 끝).

  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

Step 6 — Claude 대응 소구점 추가

  • 검색어: HTTP Request

  • 속성 설정:

    • Method = POST

    • URL = https://api.anthropic.com/v1/messages

    • Authentication = Generic Credential Type → Generic Auth Type = Header Auth → Credential = 0-6에서 만든 x-api-key 크리덴셜 선택

    • Send Headers = On → Add Header 2번:

      • anthropic-version = 2023-06-01

      • content-type = application/json

    • Send Body = On → Body Content Type = JSON → Specify Body = Using JSON → 필드의 표현식 토글(=) 켜고 아래를 그대로 붙여넣기:

{{ JSON.stringify({ model: 'claude-sonnet-5', max_tokens: 400, messages: [{ role: 'user', content: '홈쇼핑 방송 상품의 가격 경쟁력 진단이다. 아래 정보를 보고, 인터넷 최저가보다 비쌀 때 방송에서 쓸 대응 소구점 2가지(예: 방송한정가·추가 사은품·무이자·차별화 포인트)를 한국어 3줄로 제안해줘.\n상품: ' + $json['상품명'] + ' / 우리 방송가: ' + $json['우리방송가'] + '원 / 인터넷 최저가: ' + $json['최저가'] + '원(' + $json['최저가몰'] + ') / 가격차: ' + $json['가격차'] + '원' }] }) }}

  • 연결: 이전 노드 출력(●) → 이 노드 입력(●)

  • 테스트 포인트: Test step에서 content[0].text에 Claude의 응답 문장이 들어있는지 확인. invalid x-api-key 에러면 크리덴셜 값을 다시 확인하세요.

Step 7 — MD 가격진단 메일 추가

  • 검색어: Gmail

  • 속성 설정:

    • Credential: 0-6에서 만든 Gmail 계정 선택

    • Operation = Send (기본값)

    • To: 표현식 토글 끄고 → YOUR_MD@example.com (본인 이메일로 교체해서 테스트)

    • Subject: 표현식 토글(=) 켜고 → [가격경쟁력] {{ $('최저가 비교').item.json['상품명'] }} — 최저가 대비 {{ $('최저가 비교').item.json['가격차'] }}원 비쌈

    • Email Type = Text

    • Message: 표현식 토글(=) 켜고 →

■ {{ $('최저가 비교').item.json['상품명'] }}
- 우리 방송가: {{ $('최저가 비교').item.json['우리방송가'] }}원
- 인터넷 최저가: {{ $('최저가 비교').item.json['최저가'] }}원 ({{ $('최저가 비교').item.json['최저가몰'] }})
- 가격차: {{ $('최저가 비교').item.json['가격차'] }}원

[대응 소구점 제안]
{{ $json.content[0].text }}

✅ 완성 후 테스트: 트리거 노드에서 Test step(또는 Execute Workflow) → 마지막 노드까지 전부 초록불이 뜨는지 확인. 안 뜨면 그 노드를 더블클릭해 에러 메시지를 읽고, 표현식 토글(=)이 켜져 있는지부터 확인하세요.
