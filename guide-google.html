Google 크리덴셜(OAuth) 설정 — self-host n8n

Lab2~5의 Google 연결 경로는 본인 Workspace/개인 계정 OAuth를 준비한 경우 수행합니다. 미준비·정책 차단 시 CSV/로컬 대체 경로 + 강사 화면 시연으로 진행하고, Lab6 기본 경로는 CSV 파일 템플릿입니다. 계정·로그인·OAuth Credential은 공유하지 않습니다.

★핵심 1 — self-host redirect URI (Cloud와 다름!)

n8n Credential 화면(예: Google Sheets account)에 뜨는 OAuth Redirect URL:

http://localhost:5678/rest/oauth2-credential/callback
  • ★self-host = localhost:5678. (n8n Cloud는 https://<계정>.app.n8n.cloud/... 라 다름)
  • 이 URL을 Google Cloud Console의 Authorized redirect URIs에 그대로 등록해야 연결됨.
  • 포트를 바꿨으면(N8N_PORT=8080) URI도 그 포트로.

단계 — 본인 구글 계정으로 연결할 때

  1. console.cloud.google.com 접속 → 프로젝트 생성/선택.
  2. APIs & Services → Library → Google Sheets API·Google Drive API(Gmail도 쓰면 Gmail API) 검색 → 각각 Enable.
  3. Google Auth Platform → Branding/Audience(계정에 따라 기존 OAuth consent screen) → External · Testing → 앱 이름·지원 이메일 입력 → 테스트 사용자에 본인 이메일 추가.
  4. APIs & Services → Credentials → Create Credentials → OAuth client ID.
  5. Application type = Web application.
  6. Authorized redirect URIs 에 위 URL 붙여넣기: http://localhost:5678/rest/oauth2-credential/callback
  7. 생성된 Client ID · Client Secret 복사.
  8. n8n Credential 화면에 Client ID·Secret 붙여넣기 → Sign in with Google → 동의.
  9. Gmail도 같은 방식(같은 OAuth 클라이언트 재사용 가능 — Gmail API Enable 필요).

⚠️ External + Testing의 7일 만료: Sheets/Gmail처럼 identity 외 scope를 요청하는 External 앱이 Testing 상태면 refresh token이 보통 7일 후 만료됩니다. 강사 본인 계정으로 화면 시연할 때는 강의 직전에 다시 연결하고, 장기 운영은 사내 IT 검토 아래 Publishing status·검증 요건을 충족하세요. 공식 근거: https://developers.google.com/identity/protocols/oauth2#expiration

▲ 7단계 화면 — OAuth 클라이언트를 만들면 뜨는 "OAuth 클라이언트 생성됨" 창. 여기서 클라이언트 ID·Client Secret을 복사해 n8n Credential 화면에 붙여넣어요. Client Secret은 민감정보이므로 즉시 안전한 비밀 저장소에 보관하고, 화면 공유·캡처·Git 커밋을 금지합니다. 필요하면 Google Cloud Console의 Clients/Credentials에서 다시 확인하고, 유출이 의심되면 즉시 재발급하세요. 이 예시는 실제 값을 마스킹한 화면입니다.

★핵심 2 — 강의 운영 권장(자격증명 공유 금지)

  • 비개발자 각자 OAuth 설정은 10~20분+ 걸리고 막히기 쉽습니다. Lab2~5에서 OAuth를 준비하지 못했거나 정책상 차단되면 CSV/로컬 대체 경로와 강사 화면 시연으로 합류하고, Lab6은 CSV 파일 템플릿을 기본으로 진행합니다.
  • Google 시트 보조 경로는 본인 계정으로 연결합니다. 강사 본인 계정의 OAuth 자격증명은 수강생에게 공유하지 않고 강사 화면 시연에만 사용합니다.
  • External + Testing 상태의 강사 계정은 7일 만료를 고려해 강의 직전 재연결 여부를 확인합니다.

흔한 막힘

증상 원인 해결
redirect_uri_mismatch Cloud Console URI ≠ n8n 화면 URL 끝 슬래시·포트까지 정확히 일치
API not enabled / 403 Sheets·Drive·Gmail API 미활성화 Library에서 해당 API Enable
access_blocked (테스트 앱) consent screen 테스트모드 본인 이메일을 테스트 사용자에 추가
사내 계정 동의 막힘 회사 Google Workspace 정책 사내 IT에 외부 OAuth 앱 허용 확인. 해결 전에는 CSV/로컬 데이터 경로 사용

⚠️ Google Cloud Console 메뉴·화면은 자주 바뀝니다 → 강의 전 본인 화면에서 1회 dry-run 으로 경로를 확인하세요. (이 문서는 절차 안내용, 화면 라벨은 당일 기준)
